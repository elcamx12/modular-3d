# modular-3d

모듈러 건축(철골 모듈 + PC 철골 건식접합) 구조설계 보조 프로그램. 부재를 평면에 배치해 건물 모델을 만들고, 접합부를 자동 추출·직접 편집한 뒤 OpenSeesPy 로 구조해석하고, 단면 자동 설계·물량·자재비·운송 계획까지 한 흐름으로 다룬다.

> 졸업종합설계 프로젝트. UI 는 PyQt5 + Vispy(3D), 해석 엔진은 OpenSeesPy.

## 작업 흐름 (8개 탭)

`모듈 정의` → `배치 설계` → `접합부 설계` → `구조해석` → `물량` → `운송` → `공기 및 접합부` → `최종평가`

1. **모듈 정의** — 모듈/패널/수직모듈을 종속부재·개구부·실까지 묶어 "정의"로 만들어 라이브러리에 저장. 건물 파일도 직접 불러올 수 있다.
2. **배치 설계** — 부재 배치(자동 정렬·20mm 시공간격·층 자동복제·부모-자식 종속), 실(공간)·개구부·내벽, 실 용도별 하중(KDS 41 12 00), 보 단면 타입(각형강관/H형강) 선택, 저장/불러오기.
3. **접합부 설계** — 자동 추출된 접합 확인 + 직접 편집(제거/핀/강접/신규 추가/직각 ㄴ자), 같은 위치 모든 층 일괄 또는 이 층만, 다이어프램·규칙 범례, 디자인+접합 저장.
4. **구조해석** — 5개 하중조합(중력·지진 X/Y·풍 X/Y) 정적 해석, 변형형상·내부력·응력비.
5. **물량** — 표준 단면 카탈로그(각형강관 KS D 3568 / H형강 KS D 3502)에서 단면 자동 선정, 그룹 정책별 집계, 강종별 물량·자재비.
6. **운송** — 모듈·패널 무게·치수 산정, 트럭 패킹·회차·운임.

## 주요 기능

- 2D 평면 배치 + 3D 입체 확인, 정의 라이브러리, 다층 자동 복제
- 실(폴리곤+용도) / 개구부(메시 실제 관통) / 세대 내부 칸막이(내벽)
- 실 용도별 활하중 + 부가 고정하중(SDL) + 벽 자중 + 옥상 자동검출
- 보 단면 각형강관·H형강 선택 (3D I자 표시, 강축 휨 강도검토, 강종별 자동설계·물량)
- 접합부 자동 추출(R01~R09) + 사용자 직접 편집(JointOverride 등록 게이트, 평면좌표 기반 다층 자동 적용)

## 실행

```
# 소스 실행 (개발자)
my_project/venv/Scripts/python.exe -m modular_3d
# 또는
python run_modular_3d.py
```

PyInstaller 로 exe 배포 가능(`modular_3d.spec`).
