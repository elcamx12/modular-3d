# H형강 추가 · 접합부 변경 — 미해결·잠재 문제 (2026-05-25 점검)

검증 통과·수정 완료·사용자가 불필요하다고 한 항목은 제외했다. 아래만 남음.

## ⚠️ 잠재 위험 / 설계 한계

### C3 — add 복제 성능 O(N²)
- `apply_added_joints` 가 add 오버라이드마다 om.node_tags / 보 element 를 O(N²) 순회하고,
  build 가 solve 당 5회 반복된다. add 가 많고 노드 N 이 크면 느려질 수 있다(add 가 소수면
  실용상 무해). 필요 시 xy 버킷 인덱스로 개선.

### E5 — consolidate 노드 source_comp_id 판정 (확인 필요)
- 캔틸레버/코어 종속 노드가 consolidate 로 부모와 nid 통합되면 그 노드의 source_comp_id 가
  한쪽으로 정해진다. `pick_ops_joint_at` 의 "컴포넌트 간" 판정(ca==cb 면 제외)이 통합 결과에
  따라 캔틸·코어 종속 접합을 후보에서 빼거나 포함할 수 있다. 실데이터로 직접 확인 필요
  (캔틸레버/코어 접합을 실제 편집할 때 잘 선택되는지).
