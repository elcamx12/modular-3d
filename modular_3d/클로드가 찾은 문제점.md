## 진행 이력 요약

**1차 정리**: 죽은 함수 23개·436줄 일괄 제거 / 데드 임포트 14건·라인 정리 /
`단가/`·`모듈-모듈 공정표/` 잔재 폴더 삭제 / `_build_subtab_views` 가드 라인 제거.

**2차 정리**: `_module_floor_span` 공용화(`_utils/geometry.py`) /
`_alpha_label` 공용화(`_utils/format.py`) / joint_rules 매직 넘버 3건 카탈로그 등록.

**3차 정리 (2026-05-27)**:
- legacy_packer.py 안 죽은 헬퍼 2개 추가 정리 (14줄).
- `_won` 공용화 + 통화 표시 "원" 단위로 통일 (analysis_panel ↔ evaluation_panel 일관).
- 한글 파일명 리네임 — `analysis/물량산출_설계.py` → `quantity_design.py`.
- 운임 모드 토글에 거리 입력 활성/비활성 동기화 추가 (fixed_per_trip 모드면 회색).
- 정책 변경(1/2/3종) 시그널을 평가 탭에도 push — `_refresh_evaluation_panel` 헬퍼 추출.
- 운송 결과 0회차/blocked 시 사용자 알림 격상 (statusBar + 에러 메시지).
- 공정표/평가 어댑터 실패 시 dprint 대신 statusBar 노출.
- alignment 그룹(4파일)을 `ui/alignment/` 서브폴더로 분리.
- controls 그룹(3파일)을 `ui/controls/` 서브폴더로 분리 (controls.py → `__init__.py`).

**4차 정리 (2026-05-27)**:
- 9-B: `to_world` nested 21곳을 `make_local_to_world(ax, ay, rot, pos)` factory
  한 줄 호출로 통일. 본 변환 알고리즘은 그대로(`_rotate_local_to_world`).
  분리 의도(부재별 closure 캡처) 는 보존. 약 23줄 감소.

**5차 정리 (2026-05-27)**:
- 7-C: `analysis/topology.py` 의 wall_thickness 기본값 300.0 → 카탈로그
  `CORE_WALL_DEFAULT_THICKNESS_MM` / 같은 함수의 dz 임계값 5.0·500.0 → 명명 상수
  `CORE_VERTICAL_DZ_MIN_MM`·`CORE_VERTICAL_DZ_MAX_MM` / `render/opening_mesh.py`
  의 band 한계 700.0 → `WALL_HIT_BAND_MAX_MM`·`WALL_HIT_BAND_RATIO` 명명. 4건.
- 3-B 1단계: `__init__` 의 메인 탭 위젯·시그널·메뉴바·운송 wiring 블록
  (약 70줄) 을 `_setup_tabs()` 메서드로 추출. `__init__` 길이 단축.
- 3-B 4단계: `SchedulePanel.on_enter(scene_components, project_settings)` 신설.
  main_3d 의 TAB_SCHEDULE 분기에서 어댑터 import·호출을 SchedulePanel 안으로
  이관 — UI 가 자기 도메인 데이터 흐름 소유. `EvaluationPanel` 은 이미
  `_refresh_evaluation_panel` 헬퍼로 구조 정리되어 별도 이관 불필요.
- 3-B 2단계 보류: 탭 빌더 5개를 외부 파일로 이전하려 했으나 빌더가 main 의
  7+개 내부 attr (`_design_left_lay`, `_transport_splitter` 등) 를 setattr 형태로
  생성. 외부 이전 시 캡슐화 손해가 효과보다 큼 → 메서드 분리는 유지하되 같은
  파일 안에 둠.
- **3-B 3단계 (접합부 컨트롤러 분리)**: 18개 핸들러 + 9개 상태 변수 + 4개
  공유 위젯 참조 분석 후 `JointEditController` 클래스로 분리. `ui/main_3d_joint.py`
  525줄 신설, `main_3d.py` 1850→1368 (482줄 감소). 동적 dispatch 사전 검사
  (getattr/connectSlotsByName/문자열 리터럴) 0건 확인 → grep 만으로 완전 안전.
  외부 진입점은 시그널 connect 4건 + `_on_tab_changed` 3건 + `eventFilter` 3건
  으로 모두 명시적. controller 가 `self.window` 로 main 참조해서 공유 위젯
  접근. 상태 변수는 controller 가 소유.

회귀 테스트 (운송 제외) 64건 통과 — 우리 변경 회귀 0건.
