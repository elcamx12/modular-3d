# modular_3d 사용법

> 본 문서는 프로그램을 처음 실행해 부재 배치 → 구조해석 → 단면 자동 설계 → 물량산출 → 시나리오 저장까지의 모든 절차를 정리합니다. 프로그램의 설계 의도·아키텍처는 `설명서.md`, 함수·클래스 전수 목록은 `인벤토리.md` 를 참고하세요.

## 0. 한눈에 보는 작업 흐름

```
[모듈 정의 탭] 컴포넌트 정의(선택) → [배치 설계 탭] 부재 배치·하중·단면 타입 → [접합부 설계 탭] (선택) 접합 확인·편집 →
[구조해석 탭] 5 케이스 해석 → [물량 탭] 단면 자동 설계 + 물량산출 →
[운송 탭] 트럭 패킹·운임 → [공정표 탭] 공기·노무비·경비 → [종합 탭] 종합 보고서 + .case.json 저장 → [비교 탭] 케이스 비교
```

각 단계는 독립적으로도 사용 가능합니다 (저장된 시나리오 불러와서 바로 해석 등).

## 1. 실행 방법

### 1-A. exe 배포본 (권장 — 교수님용)

1. 노션에 올라온 `modular_3d.zip` (약 280 MB) 다운로드 후 임의의 폴더에 압축 해제.
2. 압축 해제된 `modular_3d` 폴더 안의 **`modular_3d.exe` 더블클릭** 으로 실행.
3. 같은 폴더의 `_internal/` 은 실행에 필수이므로 절대 분리하지 마세요.

처음 실행 시 OpenSeesPy DLL 로드와 PyQt5 플러그인 초기화로 5~10 초 소요됩니다. 콘솔창은 뜨지 않으며 (windowed 모드), 곧바로 **홈 화면**이 나타납니다. 홈 화면에서 운송 거리·지역·착공일 등 사업 공통 조건을 입력하고 **"새 프로젝트 시작"** 을 누르면 작업 탭(모듈 정의 탭부터)으로 들어갑니다.

### 1-B. 소스 실행 (개발자용)

```
my_project/venv/Scripts/python.exe -m modular_3d
```

또는 프로젝트 루트의 `run_modular_3d.py` 더블클릭 (venv 자기-재실행 가드 포함).

## 3. 부재 배치 워크플로 (디자인 탭)

배치는 항상 다음 4 단계를 따릅니다.

```
[1] 부재 종류 선택 (1~9)
       ↓
[2] 치수 입력 + Enter
       ↓
[3] PREVIEW (마우스 호버 → 고스트 표시, R/V 로 회전·앵커 조정)
       ↓
[4] 캔버스 클릭 = 확정 (자동으로 N 층 분량 한꺼번에 생성)
```

### 단계 1 — 부재 종류 선택

좌측 팔레트의 1~9 버튼 클릭 또는 **2D 캔버스에서 1~9 키** 입력. (3D 뷰에는 키 라우팅이 가지 않으므로 반드시 2D 캔버스에 포커스가 있어야 합니다 — 탭 진입 직후엔 자동 포커스.)

| 키 | 부재 | 기본 치수 (W × D × H mm) | 입력 가능 칸 |
|---|---|---|---|
| 1 | 모듈 | 3400 × 6820 × 3400 | W, D (H 는 카탈로그 고정 3400) |
| 2 | 바닥패널 | 3400 × 5000 × 200 | W, D |
| 3 | 벽패널 | 벽길이 × 200 × 3400 | W (벽길이만) |
| 4 | 캔틸레버보 | 돌출길이만 | W (돌출길이) |
| 5 | 캔틸레버슬래브 | 돌출 × 폭(자동) | W (돌출만, D 는 부모 변 길이로 자동) |
| 6 | 중간보 | 자동 | (모든 칸 비활성 — 길이 자동 산출) |
| 7 | 중간기둥 | 높이만 | H |
| 8 | 수직 3층 모듈 | 3400 × 3400 × 10240 | (모두 고정) |
| 9 | RC 코어벽 | 벽길이 × 두께 × 3400 | W (벽길이), D (두께 200~500) |

비활성 칸은 자동 결정 또는 카탈로그 고정값입니다. 비활성 칸의 표시값(예: '3400' 또는 '자동') 도 그대로 해석 모델로 전달됩니다.

### 단계 2 — 치수 입력

하단 치수 패널에 부재별 입력 칸이 활성화됩니다. **Tab** 으로 다음 칸 이동, **Enter** 로 확정, **Esc** 로 취소. 벽패널일 때는 "바닥패널과 병합" 체크박스가 함께 표시됩니다 (기본 ON).

### 단계 3 — 위치 / 회전 / 앵커 조정 (PREVIEW 상태)

치수 확정 후 캔버스가 PREVIEW 상태가 됩니다. 마우스를 따라 반투명 고스트 부재가 움직이며, 부근에 다른 부재가 있으면 자동 20 mm 갭/스냅 적용. 좌측 3D 뷰에도 동시에 고스트가 표시됩니다.

- **R 키** — 90° 회전 (0 → 90 → 180 → 270 순환). 회전 후 콘솔에 `[F5 ROTATE] 90°` 와 같이 출력.
- **V 키** — 앵커 변경 (좌하 → 우하 → 우상 → 좌상 순환). `[F5 ANCHOR] 우하` 출력.
- **마우스 호버** — 우하단 상태바에 현재 월드 좌표 X/Y 표시.

R/V 키를 누르면 사용자 의도로 간주해, 종속 부재 자동 스냅의 회전 자동 결정이 차단됩니다 (`_f5_user_rv_override` 플래그). 이후 마우스 호버로 부모 변에 인접해도 R/V 가 그대로 유지됩니다.

### 단계 4 — 캔버스 클릭 = 확정

마우스 클릭으로 부재 생성. F5 패널 (2D 캔버스 좌상단) 의 **층 수 (N) 설정** 에 따라 자동으로 N 층 분량이 한꺼번에 생성됩니다.

- 같은 group_id 부여 → 그룹 단위 undo (Ctrl+Z 1 회로 통째 사라짐)
- 콘솔에 `[F5 배치] module group=1, ids=[1,2,3], N=3` 등 출력
- 배치 직후 `record_joints` 자동 호출 → `[F5 JOINT REC] 4 코너 기록 갱신` 등 출력

## 5. 자유 이동 / 복사 모드 상세

### 5-A. M 키 (자유 이동) 동작 정책

선택한 부재의 종류에 따라 이동 대상이 다릅니다:

| 선택 부재 | 이동 대상 |
|---|---|
| 코어벽 1 장 | 자기 한 장만 |
| 코어 슬래브 | 슬래브 + 같은 그룹 코어벽 (한 묶음) |
| 모듈 / 패널 / 벽 본체 | 같은 group_id 전체 (본체 + 종속 부재) |
| 캔틸레버보 / 캔틸레버슬래브 / 중간보 / 중간기둥 | 자기 하나만 |

이동 중에도 R/V 가능. 클릭으로 새 위치 확정. 이동 후 `record_joints` 자동 재호출 → 접합 관계 즉시 갱신.

### 5-B. C 키 (복사) 동작

- 같은 컴포넌트가 새 group_id 로 복제됨 (원본 group_id 보존 X — 의도와 다른 동시 이동 방지).
- 마우스 클릭 위치가 새 그룹의 seed 부재 position 으로 사용됨. 다른 부재들은 동일 delta 만큼 평행이동.
- R/V 로 회전·앵커 변경 가능 — 모든 클론에 동일 자세 적용.

### 5-C. 그룹 단위 Undo 시나리오

```
[1] 1 키 → Enter → 클릭   →   모듈 3 장 (1F, 2F, 3F) 생성
[2] Ctrl + Z              →   3 장 통째 사라짐
[3] Ctrl + Y              →   3 장 통째 복원
```

`begin_group_action` / `end_group_action` 패턴으로 한 사용자 액션의 모든 add 가 1 액션('group_place') 으로 묶이기 때문입니다.

## 6. 코어 슬래브 생성 (별도 버튼)

RC 코어벽을 배치한 뒤에는 슬래브가 **자동 생성되지 않습니다** (2026-05-12 정책 — 자동 생성 폐지).

좌측 팔레트 하단의 **「코어 슬래브 생성/재생성」** 파란 버튼을 직접 눌러야 슬래브가 만들어지거나 다시 그려집니다.

언제 누르나요:
- 코어벽을 처음 배치한 직후
- 코어벽을 이동했을 때
- 코어벽 층 수 (N) 가 변경됐을 때
- 코어벽 추가/삭제로 ㄷ 자 / ㅁ 자 형상이 변경됐을 때

버튼이 하는 일:
1. 같은 group_id 의 기존 코어 슬래브를 모두 제거
2. 각 층 (0..N) 에 대해 그 층 코어벽들의 xy bbox 를 계산
3. bbox 영역에 슬래브 1 장 생성 (회전 0, 앵커 좌하). 슬래브 상면 z = k·H + h (코어벽 윗면), 하면 = 상면 − 두께.
4. 코어벽 두께를 슬래브 dimensions 에 박아 해석 측에서 외곽 격자가 자동으로 코어벽 상단 노드에 병합되도록 처리.

## 7. 구조해석 실행 (구조해석 탭)

### 7-A. 절차

1. 디자인 탭에서 모델을 완성한 뒤 **구조해석 탭** 클릭. 좌측 3D 뷰가 자동으로 와이어프레임 + ModelSpec 표시 모드로 전환됩니다.
2. 우측 패널 상단의 **하중조합 콤보박스** 에서 5 케이스 중 선택:

   | 표시명 | 의미 | 활성 |
   |---|---|---|
   | 1.2D + 1.6L (중력) | 자중 + 활하중. KBC 2022 영구 + 변동 조합. | ✓ 기본 |
   | KBC 2022 §0306 등가정적 지진 X | 횡력 X. Cs · W 베이스 전단. | ✓ |
   | KBC 2022 §0306 등가정적 지진 Y | 횡력 Y | ✓ |
   | KDS 41 12 풍하중 X | V=35 m/s, q=0.613V² | ✓ |
   | KDS 41 12 풍하중 Y | 동일 Y 방향 | ✓ |
   | 그 외 KBC 조합 (예: 1.4D, 1.05D+0.3L+Ex 등) | 추후 구현 | ✗ 비활성 |

3. **「해석 실행 ▶」** 버튼 클릭.

### 7-B. 결과 확인

**요약** 서브탭:
- 평형 검증율 (적용 하중 합 vs 베이스 반력 합, 1% 이내 정상)
- 최대 변위 (X/Y/Z), 최대 변위 발생 노드
- 베이스 전단 (5 케이스 모두 분리 표시)
- 노드 수, 부재 수

**부재별 내부력** 서브탭:
- 컴포넌트 (모듈 / 패널 / 벽 / 코어) 단위 트리 그룹핑
- 트리 노드 클릭 → 해당 컴포넌트의 모든 부재 펼침 → 부재 행 클릭 시 3D 뷰에서 해당 부재 강조
- 각 부재의 N (축력), Vy/Vz (전단), Mx (비틀림), My/Mz (휨), 양 끝(i, j) 값 표시

### 7-C. 변형 형상 슬라이더 (하단)

좌측 3D 뷰 하단의 슬라이더로 변형 배율 0~500× 조정 가능. 0 = 원래 형상, 500 = 시각적으로 부풀려 보이게. 슬라이더 옆 라벨에 현재 배율 표시.

### 7-D. 평형 1% 초과 시

평형이 안 맞으면 (어떤 mechanism 가능성):
- 부재 배치에 외톨이 코너가 있는지 디자인 탭에서 재확인
- 코어 슬래브 버튼을 눌러 슬래브가 정상 생성됐는지 확인
- 콘솔 출력에서 `[topology] WARN ...` 메시지 확인

현재 회귀 테스트 17 케이스 모두 평형 0.00% 통과.

## 8. 단면 자동 설계 (단면 설계 탭) · 물량 산출 (물량 탭)

단면 결정과 물량 산출은 이제 **두 개의 별도 탭**으로 나뉩니다. 단면 설계 탭에서 강재 단면을 자동 수렴·수동 조정하고, 그 결과로 물량 탭에서 본수표·슬래브 수량·자재비를 표시합니다. 아래 8-A~8-E 는 주로 단면 설계 탭의 절차이며, 본수표·슬래브·자재비 표시는 물량 탭에서 이루어집니다.

### 8-A. 사전 조건

**구조해석 탭에서 5 케이스 모두 해석을 마친 뒤** 단면 설계 탭으로 이동하면 응력비 색상과 단면 자동 설계가 동작합니다 (각 케이스 응력비를 합산해 최대치로 사용).

### 8-B. 단면 그룹화 정책 선택

우측 패널 상단 **라디오버튼** 으로 3 가지 정책:

| 정책 | 그룹 수 | 의미 |
|---|---|---|
| 1 종 | 1 | 모든 부재 동일 단면 1 개 — 가장 보수적, 가장 무거움 |
| 2 종 | 2 | 보 1 + 기둥 1 — 일반적 시공 분리 |
| 3 종 | 3 | 외곽 보 + 내부 보 + 기둥 — 최적화 수준 ↑ |

선택 변경 시 자동으로 단면 재선정 + 재해석 + 응력비 재계산이 일어납니다 (수 초 소요).

### 8-B-2. 기둥 층구간 분할 (2026-05-19 신설)

라디오버튼 아래에 **「기둥 층구간: [SpinBox]  [적용]」** 컨트롤이 있습니다. K=1 이면 기둥을 한 단면으로 통일 (기본), K≥2 면 K 개 연속 층 구간으로 분할해 각 구간 별 단면을 따로 채택. 적용을 누르면 5 케이스 envelope 수요로 동적계획법 최적분할 (강재 중량 최소) 을 수행하고, 본수표·채택 단면표·응력비 트리의 기둥 그룹 라벨이 "기둥 (1~3층) / 기둥 (4층) / 기둥 (5~7층)" 같은 한글 범위 라벨로 자동 갱신됩니다.

권장 사용: 11 층 이상 고층 모델에서 K=2~4. 단층/저층은 K=1 로 충분.

### 8-B-3. 지배 케이스 자동 선택

상단 하중조합 콤보의 값과 무관하게 단면 설계는 항상 5 케이스 envelope(절댓값 포락 + 압축 우선) 로 수행됩니다. 단면 선정 후 콤보가 "envelope" 항목으로 자동 점프해 표시 일관성을 유지합니다 — 사용자가 콤보를 다른 케이스로 바꿔도 단면 자동 설계가 다시 호출되지 않는 한 다시 envelope 으로 돌아갑니다.

### 8-C. 단면 자동 선정 알고리즘

각 그룹에 대해 응력비 ≤ 0.8 을 만족하는 가장 작은 SHS 단면을 `카탈로그/steel_sections.SHS_CATALOG` 에서 선정. 후보 SHS 약 20 종 (100×100×6 ~ 400×400×12) 중 단면적 오름차순 탐색.

### 8-D. 결과 표시 (단면 설계 탭)

**채택 단면 표** (그룹/타입별 1 줄):
- 그룹·타입명 (예: "기둥") / 채택 단면 (예: SHS 200×200×8) / 단면적 / 단위중량 / 최대 응력비 / OK·NG

**타입 목록 + 컴포넌트 3D**:
- 타입을 고르면 좌측 응력비 색이 그 타입으로 강조되고, 우측에 그 타입 대표 부재의 강재 색별 3D 형상이 표시됩니다.

> **본수표(길이·본수·중량 합계)·슬래브 부피·자재비는 이 탭이 아니라 물량 탭에서 표시됩니다.** (단면 설계 탭에서 단면이 확정되면 물량 탭이 그 결과로 수량·금액을 계산.)

**부재별 응력비 + 색상**:
- 모든 부재 행을 응력비 내림차순으로 정렬해 표시
- 색상 5 단계 (응력비 0.2 단위):

  | 응력비 | 색 |
  |---|---|
  | 0.0 ~ 0.2 | 🔵 파 (여유) |
  | 0.2 ~ 0.4 | 🟢 하 (충분) |
  | 0.4 ~ 0.6 | 🟢 초 (적정) |
  | 0.6 ~ 0.8 | 🟠 주 (한계) |
  | 0.8 ~ 1.0 | 🔴 빨 (위험) |

### 8-E. 부재 행/타입 클릭 → 3D 뷰 강조

단면 설계 탭에서 부재 행(또는 타입)을 클릭하면:
1. 3D 뷰에서 해당 부재가 강조 색상으로 점멸
2. 3D 뷰 전체가 응력비 색상 모드로 전환 (모든 부재가 응력비에 따라 5 색)
3. 우측 패널 다른 행 클릭 시 해당 부재로 강조 이동

### 9-A. 저장 (Save)

우측 속성 패널 하단의 **「AI 최적배치 실행」** 영역에 다음 5 개 입력이 있습니다.

| 입력 | 범위 | 기본값 | 비고 |
|---|---|---|---|

| 세대 면적 (m²) | 20 ~ 200 | 60 | 한 세대 면적 |

- 기존 배치를 고정으로 두고, 빈 자리만 AI 가 최적 채움
- 5 입력값을 제약 조건으로 사용
- 결과로 N 장 모듈 + 코어 배치를 자동 생성

## 11. 접합부 설계 탭 (배치 설계 ↔ 구조해석 사이)

### 11-A. 탭 개요

배치 설계 탭에서 부재 배치를 끝내고 **접합부 설계 탭** 을 클릭하면 좌측 3D 가 자동으로 와이어프레임 모드(ModelSpec 표시) 로 전환됩니다. 단 구조해석 탭과 달리 **5 케이스 솔버는 실행되지 않습니다** — 결합 위치만 빠르게 확인·편집할 수 있도록 spec/ops 빌드만 수행. 접합을 바꿀 때마다 와이어프레임이 즉시 다시 그려집니다.

### 11-B. 접합부 편집 (구현 완료)

자동으로 추출된 접합을 3D에서 직접 골라 성질을 바꾸거나 제거하고, 새 접합을 추가할 수 있습니다.

- **변경·제거**: 우측 "접합부 편집 활성" 을 켜고 접합을 좌클릭 → 선택이 노란선으로 강조됩니다. "제거 / 핀 / 강접" 버튼으로 그 접합을 없애거나 회전 자유(핀)·회전 구속(강접)으로 바꿉니다. 같은 자리에 종류가 다른 수직접합이 겹쳐 있으면, 범례에서 보고 싶은 종류만 켜고 그 종류만 골라 편집할 수 있습니다.
- **다층 일괄 / 이 층만**: 기본은 같은 평면 위치의 **모든 층**에 함께 적용됩니다(한 층만 바꿔도 위로 쭉). "이 층만 적용" 을 체크하면 클릭한 그 층의 접합에만 적용합니다.
- **신규 접합 추가**: "접합 추가 모드" 를 켜고 부재(보) 모서리 위 두 점을 차례로 클릭합니다. 점을 고를 때 미리보기 점·연결선·스냅 후보가 보이고, 핀/강접을 고를 수 있습니다. 점 자리에 절점이 없으면 그 보를 분할해 절점을 새로 만들어 잇습니다. **스냅한 점이 기존 꼭지점(초록)인지 보 위 임의 점(주황)인지가 실제 연결 방식에 그대로 반영**됩니다.
- **직각(ㄴ자) 결합**: "직각(ㄴ자) 결합" 을 켜면 평면·높이가 모두 다른 두 점을 중간 가교 절점을 거쳐 수직+수평 두 단계로 잇습니다. 직각·추가 접합은 한 묶음으로 선택·제거되며(위-중간-아래), 제거 시 허공에 남는 가교 절점도 함께 정리됩니다. 자동 생성된 직각접합(바닥패널↔모듈 등)도 똑같이 선택·변경·제거됩니다.
- **모든 접합 변경 초기화**: 이 디자인의 모든 접합 변경(제거·핀·강접·추가)을 지우고 자동 규칙 상태로 되돌립니다.
- **제거 시 경고**: 접합 제거로 구조가 불안정(메커니즘)해질 수 있으면 즉시 경고합니다(제거 자체는 막지 않음 — 구조해석 탭에서 상세 확인).

### 11-C. 저장 / 불러오기

- **저장**: 이 탭의 "디자인 + 접합 변경 저장" 버튼으로 현재 건물과 접합 변경을 **기존 건물 저장과 같은 양식(같은 JSON)** 으로 저장합니다. 접합 변경이 부재·실·개구부와 함께 들어갑니다. (불러오기는 배치 설계 탭의 불러오기 버튼을 사용)
- **불러오기 정책(3케이스)**: 저장한 파일을 배치 설계 탭에서 불러온 뒤 이 탭으로 오면 ① "저장된 접합 사용 / 새 자동 계산" 을 묻고, ② 디자인이 바뀌었으면 자동으로 초기화하며, ③ 디자인 그대로 다시 들어오면 "유지 / 초기화" 를 묻습니다.

### 11-D. 그 외 패널

- **규칙 ID 범례** — 현재 spec 에 등록된 결합의 `rule_id` 집합을 자동 수집해 색 점 + 체크박스로 표시. 종류별로 시각화를 켜고 끌 수 있습니다(실제 접합은 유지, 화면 표시만).
- **다이어프램 시각화** — 같은 바닥(모듈·바닥패널·코어슬래브)이 한 덩어리처럼 거동하는 다이어프램을 표시.
- **합성거동** 토글 — 현재 옵션만 노출, 해석 로직 미반영(향후).

### 11-E. 구조해석 탭과의 상호작용

접합부 설계 탭에서 접합을 바꾼 뒤 구조해석 탭으로 이동하면, **자동으로 spec/ops 가 다시 빌드되고 5 케이스 솔버가 재실행** 됩니다(접합 변경이 해석·물량까지 반영됨, 자동 규칙보다 사용자 변경 우선).

## 12. 자주 묻는 점 (FAQ)

**Q1. 부재를 배치했는데 기둥이 안 보입니다.**
- 모듈 높이가 0 으로 전달되는 버그는 2026-05-13 수정됨 (치수 패널의 비활성 필드 처리). 그래도 안 보이면 카메라가 너무 멀거나 부재가 카메라 뒤쪽일 수 있음 → 마우스 휠 줌 아웃, 우클릭 드래그로 시점 변경.

**Q2. 5 케이스 중 일부만 해석되고 멈춥니다.**
- 평형 검증율이 1% 를 넘으면 자동 경고. 대개 외톨이 코너 또는 미지원 슬래브 코너 때문 — 디자인 탭에서 부재 배치를 다시 점검 후 재시도. 코어 슬래브 버튼을 안 눌렀을 가능성도 확인.

**Q3. 저장한 시나리오를 불러오면 위치가 어긋납니다.**
- 구버전 scene 마이그레이션은 자동 적용되지만, parent_id 추정이 실패할 수 있음. 디자인 탭에서 직접 이동·재배치로 수정 가능. 또는 회귀 시나리오 (`scene.json` 등) 를 사용.

**Q4. Undo 했는데 모듈 1 개만 사라지지 않고 그룹 전체가 사라집니다.**
- 의도된 동작. 같은 클릭으로 만들어진 N 층 분량은 한 group_place 액션으로 묶여 1 회 Undo 로 통째 사라지게 설계됨. 1 개씩 지우려면 그 부재를 클릭 → Delete (단일 부재 삭제는 현재 그룹 전체 삭제로 통일).

**Q5. R/V 키가 안 먹힙니다.**
- 키 라우팅은 2D 캔버스에 포커스가 있을 때만 동작. 치수 입력 칸에 포커스가 있으면 그 칸의 키 입력으로 처리됨. 치수 확정(Enter) 직후엔 자동으로 캔버스에 포커스가 돌아옵니다.

**Q6. 층 수를 바꿔도 3D 가 안 바뀝니다.**
- 2026-05-13 수정됨. SpinBox 변경 → emit 시그널 → controller 가 _refresh_2d 호출 + viewer 재구성. 그래도 안 되면 다른 SpinBox 한 번 클릭 후 다시 시도.

**Q7. 캔틸레버보를 변에 나란히 붙이고 싶습니다.**
- 현재 정책상 캔틸레버는 부모 외곽 변에 수직으로만 돌출됩니다 (사용자 피드백 v2 정책). 변에 나란히 붙이려면 STRUCT_WALL 또는 별도 BeamData 직접 추가가 필요.

**Q8. 회전이 90° 단위로만 됩니다.**
- 의도된 제한. 모듈러 + 직교 격자 가정으로 자유 각도 회전은 지원하지 않음.

**Q9. 콘솔 창이 안 떠서 디버그 메시지를 못 봅니다.**
- exe 는 windowed 모드라 콘솔 없음. 소스 실행 (`python -m modular_3d`) 으로 돌리면 콘솔에 모든 print 출력 보임.

**Q10. exe 가 시작 시 5~10 초 멈춰 있습니다.**
- 정상. OpenSeesPy DLL 로드, PyQt5 플러그인 초기화, Vispy 백엔드 준비 등. 두 번째 실행부터는 Windows 캐시로 더 빠름.

## 13. 폴더 구조 (배포본 기준)

```
modular_3d/                  ← 노션에서 받은 zip 의 루트
├─ modular_3d.exe            ← 더블클릭 실행
└─ _internal/                ← 라이브러리 (절대 분리 금지)
    ├─ openseespy/
    │   └─ opensees.pyd      ← OpenSees 핵심 DLL
    ├─ vispy/
    ├─ PyQt5/
    │   └─ Qt5/plugins/
    ├─ ffi-7.dll             ← libffi 보조 (한글 경로 회피)
    ├─ ffi-8.dll
    ├─ ffi.dll
    ├─ modular_3d/           ← 본 패키지 .pyc
    │   ├─ 카탈로그/
    │   ├─ analysis/
    │   ├─ model/
    │   ├─ render/
    │   ├─ ui/
    │   └─ io/
    └─ (수백 개 dll, pyd, py)
```

`_internal/` 은 PyInstaller 가 묶은 모든 의존성과 한글 폴더 회피용 보조 DLL 이 들어 있어, exe 파일만 분리하면 절대 실행되지 않습니다.
