# 모듈-모듈 공정표 — 데이터 연동 안내

함께 작업하는 친구에게: 아래는 우리 공정표 프로그램이 **어떤 데이터를 원하는지** 정리한 거야.
네 프로그램(scene.json 생성)이 이 형식에 맞춰주면 우리 프로그램이 자동으로 읽어서 공기·비용을 계산해.

---

## 1. 이 폴더 구성
- `모듈러주택_공정표.html` : 공기(공사기간) + 경제성(노무비·경비) 자동계산 프로그램. **브라우저로 열면 바로 실행.**
- `refs/` : 프로그램이 쓰는 근거 이미지 (그대로 둘 것 — html과 같은 폴더에 있어야 작동).
- `scene.json` : 예시 데이터 파일.
- `근거자료/` : 계산 근거 원본 PDF (OTKCRK·광양·켄텍·LH지침·표준품셈/노임/기계경비).

## 1-1. 코드 / 저장소
- **`모듈러주택_공정표.html` 이 파일이 곧 전체 코드야.** 단일 파일 안에 HTML + CSS + JavaScript(모든 계산 로직)가 `<script>` 한 곳에 들어있음. 메모장이나 VS Code로 열면 코드를 바로 볼 수 있어.
- **전체 코드 + 변경 이력 (GitHub):** https://github.com/Song-Jung-Hun/modular-schedule
  - 코드를 수정·diff·이력 확인하려면 여기서 보는 게 제일 편함.

## 2. 프로그램이 하는 일
입력값(층수·모듈·면적·코어·크레인·가동율 등)으로 **코어병행형 모듈러**의 공사기간과 비용을 자동 계산.
화면 위 **"📂 파일 불러오기"** 버튼으로 scene.json을 넣으면 → 층수·모듈수·면적·코어·수평접합을 자동으로 채워줌.

## 3. scene.json에 넣어줬으면 하는 것

### (A) summary (요약값) — 있으면 이걸 최우선 사용 (가장 안정적)
JSON 맨 위에 이 묶음을 추가해줘:
```json
"summary": {
  "floors_above_ground": 3,          // 지상 층수
  "modules_total": 21,               // 총 모듈 개수
  "modules_per_floor": 7,            // 층당 모듈 수
  "footprint_area_m2": 211,          // 건물 1층 바닥면적 (m²)
  "core_area_per_floor_m2": 17,      // 코어(계단·EV) 한 층 바닥면적 (m²)
  "vertical_joints_total": 0,        // 수직접합(위아래 모듈) 총 개수
  "horizontal_joints_total": 0,      // 수평접합(옆 모듈) 총 개수
  "module_max_weight_t": 0,          // 최대 모듈 중량 (t)
  "basement_floors": 0               // 지하 층수 (없으면 0)
}
```

### (B) components (부재 목록) — 지금 형식 그대로 OK. 단 아래만 보강 부탁:
- **모듈↔모듈 접합**: 각 모듈의 `joint_records`에 "옆에 붙는 모듈"을 넣어줘.
  - `target_comp_id` = 붙는 상대 모듈 id, 접합 위치 `target_xy`/`target_z`.
  - 한 쌍에 접합이 여러 개면 각각 기록 (우리가 위치로 중복 제거함).
  - **지금은 모듈 joint_records가 비어 있어서, 없으면 우리가 좌표로 인접 추정 중.**
- **수직모듈**: `comp_type: "vertical_module"`, `height`로 관통 층수 판단.
  - 자체 층간 수직접합은 없음(한 덩어리). 단 옆 일반모듈과 닿는 곳은 접합으로 셈.

### (C) 좌표·단위 규칙
- `position` = 모듈의 **모서리(min-corner)**, 회전은 그 모서리를 기준으로 회전.
- 단위: **좌표 = mm**, summary **면적 = m²**, **중량 = t**.

## 4. 우리 프로그램이 데이터 읽는 우선순위
1. `summary` 값 (있으면 최우선)
2. 모듈 `joint_records` (실제 접합)
3. 좌표 인접 추정 (위 둘 다 없을 때)

## 5. 공기 계산 핵심 (참고)
- **한 층 = max(양중+수직접합, 수평접합)** — 양중과 접합을 병행(동시)으로 봄.
- 수직접합은 양중에 합쳐지고, 수평접합은 양중과 동시 진행.
- 코어는 층별로 올라가고, 모듈은 그 층 코어 완료 후 설치(코어병행형).
- 지역 가동율(기상청 날씨 비작업일)로 실작업일 → 달력일 환산.

## 6. 근거 (어디서 나온 숫자인가)
- 토공·기초·1층·코어·옥탑 = **켄텍 대학원숙소** 실적 (면적 비례)
- 수직접합 = **OTKCRK** 천안두정 볼트체결 (0.025일/접합)
- 지하층 골조 = **광양생활관** 실적
- 마감·부대 = OTKCRK + LH 지침
- 노임 = 2026 시중노임 / 장비 = 2025 기계경비산출표 / 품 = 표준품셈
