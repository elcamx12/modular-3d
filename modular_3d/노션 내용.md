# 졸업종설 작업 정리

## 1. 처리 완료한 항목

### 1-1. 구조 해석 기반

- **접합부 처리 로직 구현 완료** ✅
- **코어 트러스로 환산 완료** ✅ (단, 강성 검증 미완 — 트러스로만 만든 상태)
- **다이어프램 분할 완료** ✅ (각 컴포넌트별 거동, 오류 수정 완료)

### 1-2. 디자인 탭 (2개로 분리: 모듈 정의 / 배치 설계) ✅

- **정의 라이브러리 저장·불러오기** ✅ (json 영구 저장, 단일 층 1세트, 건물 파일 직접 불러오기 지원)
- **정의 탭 부재 편집** ✅ (치수·배치·이동 등)
- **배치 탭** ✅
    - 실 구성(폴리곤+용도), 개구부(벽·슬래브 실제 관통)
    - 모듈 4면 비내력 벽 (하중·물량 0)
    - 좌측 패널에서 정의 가져오기 (그룹 고스트 + R/V/클릭, 층 자동 복제)
    - 내벽 직접 배치 (부모 종속, 다층 자동 복제, 개구부 적용, 반투명)
- **배치 탭 하중 정의** ✅ (KDS 41 12 00)
    - 실 용도별 활하중 + 부가 고정하중(SDL)
    - 슬래브별 면적가중 평균, 옥상 자동검출 (지붕 1.0 / SDL 2.5)
    - 벽 자중 (외부 55 / 내부 30 자동판별, 개구부 차감)
    - 노드 추가 없이 둘레 보 등가하중 처리
- **보 각형강관·H형강 선택** ✅
    - 부재 단위 단면 타입 선택, 종속·합체 부재는 부모 따라감
    - 3D 표시(H형강은 I자), 구조해석·자동설계·물량/자재비 모두 강종 분리 반영
    - 기둥은 항상 각형강관

### 1-3. 접합부 설계 탭 ✅

- 3D 픽킹으로 접합 제거 / 핀↔강접 변경 (같은 위치 겹친 다른 종류도 구분)
- 신규 접합 추가 (보 위 두 점 클릭 + 핀/강접 선택, 미리보기·스냅 후보 표시)
- 직각(ㄴ자) 결합 추가 (가교 절점 자동 생성, R03 방식)
- 다층 일괄 / 이 층만 옵션 (xy 평면 위치 매칭)
- "모든 접합 변경 초기화" 버튼, 메커니즘 경고
- 저장(같은 양식 json) + 불러오기 3케이스 정책
- 구조해석 5개 하중조합·물량까지 자동 반영

### 1-4. 운송 탭 ✅ (2026-05-26~27 완료)

- **1순위 정리·소규모** — 도로 등급 입력 제거 → 프로젝트 설정의 현장 운송 제한(GVW·폭·높이) / 적재 간격 고정값화 / 1회 고정 운송비 운임 추가 / 강종 일반화 (H형강 운송 크래시 수정)
- **2순위 회차 배분** — FFD 단일 그리디 → **Best-Fit + 다중 시드 54 + VND 5종 + 무게중심 보정**. 자세(LYING/STANDING), 적층 기하, 모듈 4.5m 합산, 종속 floor 모두 통합. 평균 +35% 절감, 회귀 0
- **3순위 벽 세움 운송** — A-frame + STANDING 자세 통합, LYING/STANDING 두 자세 후보 비교
- **5순위 3D 렌더링** — Plotly → **Three.js + OrbitControls + CSS2DRenderer**. 좌·중·우 3단 분할, 시네마틱 배경, 카메라 프리셋 5종, 동일 결과 회차 그룹화, 양방향 동기화(회차표↔경제성표↔3D), 카메라 평행이동
- **캔틸 옵션 제거** (2026-05-27) — 항상 부모 화물에 기하 종속(같은 회차)
- **사실적 부재 단위 렌더링** (2026-05-27) — 박스가 아닌 실제 부재(기둥·보·슬래브·벽채움·캔틸레버 등)로 표시, 회전·앵커 정합

### 1-5. 공정표 탭 ✅ (2026-05-27, 이전 "공기 및 접합부")

- 팀원 HTML 임베드 (`schedule/모듈러주택_공정표.html` + refs)
- 자동주입(Python→JS): 우리 배치·프로젝트 설정 → JS importScene
- 결과 푸시(JS→Python): QWebChannel 로 평가 탭에 결과 전달
- 자동주입 항목 6개 + 지역·착공일·모듈 폭/길이/개수 UI 잠금 (이중 입력 차단)
- 사용자 직접 입력만 노출: 지하층·크레인·양중속도·접합속도·코어선행일·유가·모듈 중량
- 접합속도 0 입력 차단, 회귀 테스트 7건 통과

### 1-6. 평가 탭 ✅ (2026-05-27, 이전 "최종평가")

- 단일 스크롤 페이지 (A 건물 개요 / B 부재 구성 / C 물량·자재비 / D 운송 / E 공기 / F 종합 비용)
- 사용자 입력 없음 — 앞 탭 결과 자동 수집
- 세대 개념 제거 (아파트라 1모듈≠1세대)
- 헤드라인 5개: 총 층수 · 지하층 · 총 모듈 수 · 1층 footprint · 연면적
- 비용 5분류: 자재비 / 운송비 / 노무비 / 경비 / 공사비(=합계)
- 정책(1종/2종/3종)은 물량 탭의 선택을 그대로 표시 (이중 입력 방지)
- 미실행 탭은 영역별 회색 안내
- 케이스 저장 `.case.json` (QFileDialog, 완전 스냅샷)
- 회귀 테스트 11건 통과

### 1-7. 코드 오류 수정·개선

- 부재별 내부력·팝업창 값 불일치 버그 ✅
- 캔틸레버 슬래브·보 길이 증가 버그 ✅
- 구조해석·물량산출 결과 가독성 개선 ✅
- 10가지 항목(약 60+건) 코드 점검 → 3건 보류, 나머지 모두 해결 ✅
    - 죽은 코드, 데이터 일관성, UI 라벨 vs 실동작, 에러 처리, 매직 넘버, 시그니처/타입 불일치, 좌표/단위, 회귀 위험, 성능, import/환경

### 1-8. 문서

- **프로그램 개요.md** 작성 + 최신 동기화 ✅

## 2. 작업해야 하는 항목

### 2-1. UI 디자인 수정

기능을 구현해 두고 디자인md로 디자인하거나, 이미지로 디자인을 만들고 (PPT 만들듯이) 각 버튼 위치에 실제 작동하는 버튼을 숨겨서 구현 가능.
기존 3d 렌더링을 운송 3d렌더링처럼 Three.js 기반으로 수정 

### 2-2. 디자인 탭

- 대표 표준모델 프리셋 (LH 평형별) - 추후 추가 예정

### 2-3. 접합부 설계 탭

- 보 합성거동 옵션 (사용자가 직접 묶기 + 강재 단면 크기를 최대한 같게 유지하도록 자동 합성하는 옵션)

### 2-4. 구조해석

- 코어 단순화 (현재 트러스 환산만 — 강성 검증·계산 모델 보완)
- 프로그램 구조해석 결과 vs 실제(상용) 해석 결과 비교
- 하중조합 추가 (KDS 41 12 00 — 1.4D 자중 단독, 0.9D 전도방지, 설하중 동시 등)

### 2-5. 물량

- 물량 산출 방법 정합성 파악

### 2-6. 공정표

- ProjectSettings 통합 — 운영 파라미터(크레인·접합속도·코어선행일·유가·지하층) 영구 저장 (2차 계획)

### 2-7. 비교 탭

- 평가 탭에서 저장한 `.case.json` 파일을 3개까지 직접 골라 나란히 비교
- 평가 탭에 슬롯/미니뷰 없이 본 화면 파일 선택으로 일원화

### 2-8. 도움말
