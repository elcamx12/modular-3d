# 구조해석 탭 수정 계획서 (2026-05-30)

## 1. 작업 배경 / 사용자 확정 사항
구조해석 탭(우측 AnalysisPanel + 좌측 3D)을 정리하고 하중조합을 실제 KDS 조합으로 확장한다.

- **컨투어 콤보 · 자유도 색 체크박스 → 완전 제거**(UI 위젯·시그널·controls 연결 삭제).
  좌측 3D 컨투어 색칠 백엔드는 영구 '끄기' 상태로만 남김(메서드는 보존, 호출 안 됨).
- **물량 탭 응력비 색칠은 절대 유지**(ratio_view_changed 경로 — 위 제거와 무관).
- **요약 탭 제거** → 구조해석 탭에는 '부재별 내부력' 하나만. 탭바(QTabBar) 숨겨 탭 없이 표만.
  (물량·운송은 별도 메인 탭에서 set_visible_subtabs 로 단일 노출 — 시각 영향 없음.)
- **부재별 내부력 표 폭 과대 문제** → 임의 여백(+24) 제거, 정확한 폭으로.
- **종속 부재(캔틸레버보 등)는 부모 모듈/패널 라벨 바로 밑에 나열.**
  예: '모듈A-2 캔틸레버보1' 은 '모듈A-2' 직후. 구조해석·물량 두 트리 모두.
- **하중조합 7개 중 5개 실제 구현** + **기존 지진/풍 케이스도 중력 포함 진짜 조합으로 수정**.
  - 설하중(S) 모델이 코드에 없음 → 설하중 들어가는 2개 조합은 **제외**('추후 구현' 유지).
  - 지진·풍의 **±방향 모두 계산** → 지배조합이 그 중 최악을 잡음(콤보 항목은 안 늘림).

## 2. 하중조합 설계 (선형 중첩)
해석은 선형 탄성 정적 → 부재력·변위가 하중에 선형. 기본 6개만 실제 해석하고 나머지는 산술 중첩.

**기본 해석(내부용, dropdown 미노출)** — 6회:
- D : 1.0×사하중(self+slab), 중력 eleLoad (dl=1, ll=0)
- L : 1.0×활하중 (dl=0, ll=1)
- Ex, Ey : 등가정적 지진 (순수 횡력, 기존 그대로)
- Wx, Wy : 풍하중 (순수 횡력, 기존 그대로)

**노출 조합(dropdown / 지배조합 envelope 대상)** — 부재력 중첩으로 합성:
| 내부 키 | 표기 | 합성식 |
|---|---|---|
| ENVELOPE | 지배조합 (전체 조합 envelope) | 아래 전체의 부재별 절댓값 최대 |
| 1.4D | 1.4D (자중 단독) | 1.4·D |
| D+L | 1.2D + 1.6L (중력) | 1.2·D + 1.6·L |
| Ex | 1.2D + 1.0L ± 1.0Ex (X 지진) | (1.2D+1.0L) ± Ex |
| Ey | 1.2D + 1.0L ± 1.0Ey (Y 지진) | (1.2D+1.0L) ± Ey |
| Wx | 1.2D + 1.0L ± 1.0Wx (X 풍) | (1.2D+1.0L) ± Wx |
| Wy | 1.2D + 1.0L ± 1.0Wy (Y 풍) | (1.2D+1.0L) ± Wy |
| Ex_OT | 0.9D ± 1.0Ex (X 지진 전도방지) | 0.9D ± Ex |
| Ey_OT | 0.9D ± 1.0Ey (Y 지진 전도방지) | 0.9D ± Ey |
| Wx_OT | 0.9D ± 1.0Wx (X 풍 전도방지) | 0.9D ± Wx |
| Wy_OT | 0.9D ± 1.0Wy (Y 풍 전도방지) | 0.9D ± Wy |

**±합성 규칙**: plus = grav+lat, minus = grav−lat. 각 부재의 양단 6성분(N,Vy,Vz,T,My,Mz)을
성분별로 |plus|·|minus| 중 큰 쪽 값을 채택(부호 보존) → 표·지배조합이 최악을 본다.
- member_forces, member_stations(5×6) 모두 동일 규칙으로 합성.
- node_disps / base_reactions / 적용하중 등은 대표값으로 plus 조합 사용(표시용).
- equilibrium_ratio 는 합성 조합에선 0(의미 없음, 요약 미표시).

**제외(추후 구현 유지)**: 1.2D+1.6L+0.5S, 1.2D+1.0L+0.2S+1.0Ex.

## 5. 위험 / 주의
- ± 합성은 성분별 독립 최대 → 한 부재 안에서 N은 plus, M은 minus 가 섞일 수 있음(보수적, 설계엔 안전측).
- 기존 'Ex' 키 의미가 '순수 횡력'→'1.2D+1.0L±Ex'로 바뀜. controls·panel 은 키 문자열만 쓰므로 호환되나, **'Ex' 결과를 순수 횡력으로 가정하던 곳이 없는지** 확인 필요(현재 없음 — 횡력 미사용 주석).
- 기본 해석 6회(기존 5회) — 시간 소폭 증가, 합성은 산술이라 무시 가능.
