# 운송 개편 검증 체크리스트 (UI 기반)

- 작성: 2026-05-26
- **신규 패커는 이미 앱에 연결됨** — 평소처럼 앱을 띄워서 운송 탭에 들어가 [▷ 운송 계산 실행] 버튼을 누르면 그게 신규 패커의 결과입니다.
- 이 체크리스트는 *앱 화면에서 관찰 가능한 동작* 을 페이즈별로 정리한 것입니다.
- 사용 방법: 앱을 띄우고 각 항목을 직접 동작시켜본 후 통과 시 `[x]` 체크. 이상이 있으면 [ 발견된 문제 ] 에 적어주세요.

> **좌표 약속 (UI 입력 시 헷갈리기 쉬움)**
> - **길이 (length)** = 트럭이 가는 방향 (앞↔뒤). 트럭 적재함의 *긴* 쪽.
> - **폭 (width)** = 트럭 옆 방향 (좌↔우). 트럭 적재함의 *좁은* 쪽 (3,000 mm 기준).
> - **높이 (height/thickness)** = 위↔아래. 모듈은 height, 패널은 thickness.
> - 예) 모듈을 4500×3400 으로 입력 = *길이* 4500, *폭* 3400 → 트럭 폭 한도 (3000 + 양쪽 여유 200×2 = 3400) 이내라 OK.
> - 예) 모듈을 3400×4500 으로 입력 = *길이* 3400, *폭* 4500 → 트럭 폭 한도 초과 → 거부. *입력 순서 헷갈리지 않도록 주의*.

## Phase 4 — Best-Fit 자유 배치 + 모듈 4.5 m 합산

### 시도 C — L 자 패널 + 작은 floor (안쪽 슬롯 적층)

> **참고**: 신규 패커는 *옆자리 (FLOOR) 가 길이 여유 안에 들어가면* 옆자리를 먼저 선택. *어디 들어가든 회차 1 회면 기능적으로 동등*. 안쪽 슬롯 적층을 *강제로* 보고 싶으면 두 패널 길이 합이 트럭 유효 길이를 넘게 구성:
> - L 자 패널 길이 **8,000 mm** + 안쪽 작은 floor 길이 **5,000 mm**
> - 합 13,000 mm > 저상 유효 11.6 m → 옆자리 불가 → 안쪽 슬롯 자동 선택

- L 자 패널 8,000 × 3,000 + 작은 floor 5,000 × 2,400 입력
- [▷ 운송 계산 실행]

### 확인 C

- [ ] **회차 수 = 1**
- [ ] 작은 floor 가 L 자 패널의 *안쪽 슬롯* 에 적층된 형태로 표시 (Top 도식에서 점선 박스)

## Phase 5 — 다중 시드 → 적은 회차 수

### 시도

- 모듈 10 + 패널 30 정도 (실제 프로젝트 화물)
- [▷ 운송 계산 실행]
- 회차표 + 적재율 sub-탭 확인

### 확인

- [ ] 평균 적재율(중량) *50 % 이상* 회차가 다수
- [ ] 화물 0 매인 빈 회차 없음
- [ ] 막힌(blocked) 화물 0 매
- [ ] [▷ 운송 계산 실행] 을 *두 번 연속* 실행 → 결과 완전 동일 (고정 시드)

### 트럭 종류별 선택 비율은 비용 모드에 좌우됨

> 신규 패커의 *기본 비용 모드는 `fixed_per_trip`* (회차당 1 회 고정비, 트럭 종류 무관 동일 단가). 이 모드에선 모든 트럭이 같은 단가라 *큰 트럭에 한꺼번에 싣는 게 회차 수를 줄여 비용이 더 싸짐* → 광폭 선호.
>
> 다운그레이드 동작을 보려면 *모드를 바꿔야* 합니다:
> - **요금표(`freight_table`)**: 저상 60 만 / 광폭 70 만 / A-frame 80 만 → 저상이 *싸다* → 저상 우선 선택
> - **km 단가(`per_km`)**: 트럭별 km 단가 차이로 비슷한 효과

### 시도 (비용 모드 변경)

- 운임 방식 콤보를 **요금표(`freight_table`)** 로 변경
- 결과 재실행 또는 콤보 변경 시 자동 갱신

### 확인

- [ ] 회차 트럭 분포가 *저상 비중 증가* — 광폭은 *꼭 필요한 회차에만*
- [ ] 적재율 수치는 비슷하거나 더 좋아짐
- [ ] 경제성 sub-탭 총 비용이 fixed_per_trip 일 때 보다 *합리적 (작아짐)*
