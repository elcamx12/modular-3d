# UI 인터랙션 시나리오 카탈로그 (M0 산출물)

작성: 2026-05-28 (지속 갱신)
목적: 모듈정의 + 배치설계 탭의 *모든* 사용자 입력 → 화면 결과 매핑.
완전성 기준: `02_UI_인터랙션_자동추출.md` 의 모든 시그널·핸들러가 본 카탈로그
어딘가에 등장해야 함. 등장하지 않으면 *누락* 또는 *죽은 코드*.

## 시나리오 항목 표기 규칙

각 시나리오는 다음 6필드로 기록:

- **번호** — 탭코드.N (D = 정의탭, P = 배치탭, A = 2D캔버스 공통, C = 카메라/뷰포트 공통)
- **입력** — 사용자 행동 (예: "팔레트의 모듈 타입 1 버튼 클릭")
- **경유 코드** — 시그널·핸들러·함수 (자동 추출에서 매핑)
- **결과 (모델)** — Scene·components·rooms 등 데이터 변경. 골든 마스터 비교 대상.
- **결과 (화면)** — 위젯·라벨·메쉬 변화. 사용자 spot-check 대상.
- **회귀 검증 방법** — AI / 사용자 / 둘 다.

---

## 카테고리 구조

1. 정의 탭 (D.1 ~)
   - D.1.x — 좌측 팔레트
   - D.2.x — 중앙 3D 캔버스
   - D.3.x — 중앙 2D 캔버스
   - D.4.x — 하단 치수 입력
   - D.5.x — 우측 부재 속성 패널
   - D.6.x — 우측 실 속성 패널
   - D.7.x — 우측 정의 라이브러리
   - D.8.x — 탭 진입·전환
2. 배치 탭 (P.1 ~) — D 와 유사 구성, 차이만 별도 기록
3. 2D 캔버스 공통 동작 (A.1 ~)
4. 카메라/뷰포트 공통 동작 (C.1 ~)
5. 단축키 (K.1 ~)

# 1. 정의 탭 (D)

## D.1 좌측 팔레트

### D.1.1 모듈 타입 버튼 1~9 클릭 (`on_select` 콜백)
- **입력**: 팔레트의 모듈/패널 타입 버튼 1~9 중 하나 클릭
- **경유 코드**:
  - `PalettePanel.on_select` → `DefineTab._on_palette_select(comp_type)`
  - → `canvas.handle_palette_select(comp_type)` (2D 캔버스)
  - → `DesignPropertiesPanel.refresh_active(comp_type)`
- **결과 (모델)**: Scene 직접 변경 없음 — *배치 모드만 활성화*
- **결과 (화면)**:
  - 2D 캔버스: 해당 타입의 *배치 미리보기 마우스 추종* 모드 진입
  - 우측 속성 패널: 활성 타입 표시 갱신
  - 팔레트: 다른 모드 버튼(실/개구부) 토글 해제
- **회귀 검증**: AI (속성 패널 활성 타입 dict 비교) + 사용자 (미리보기 시각)

### D.1.2 모듈 타입 None 전달 (모드 해제)
- **입력**: 같은 버튼 재클릭 등으로 comp_type=None
- **경유**: `_on_palette_select(None)` → `_props.refresh_active(None)`
- **결과 (모델)**: 변경 없음
- **결과 (화면)**: 속성 패널 활성 타입 표시 해제
- **검증**: AI

### D.1.3 "실 모드" 토글 ON
- **입력**: 팔레트 실 모드 체크박스/버튼 ON
- **경유**: `PalettePanel.on_room_mode_toggle(True)` → `DefineTab._on_room_mode_toggle(True)` → `canvas.set_edit_mode('room')`
- **결과 (모델)**: 변경 없음
- **결과 (화면)**: 2D 캔버스 편집 모드 'room' 전환 (커서·하이라이트 변화)
- **검증**: 사용자 (시각)

### D.1.4 "실 모드" 토글 OFF
- **입력**: 실 모드 OFF
- **경유**: `_on_room_mode_toggle(False)` → `canvas.set_edit_mode('component')` + `_show_room_props(None)`
- **결과 (화면)**: 편집 모드 'component' 복귀 + 실 속성 패널 숨김 + 부재 속성 패널 표시
- **검증**: 사용자 + AI (패널 visible 상태 비교)

### D.1.5 "실 그리기" 버튼
- **입력**: 팔레트 "실 그리기" 클릭
- **경유**: `DefineTab._on_room_draw()` → `canvas.start_room_draw()`
- **결과 (화면)**: 2D 캔버스 실 폴리곤 그리기 모드 시작 (클릭으로 꼭짓점 찍기)
- **검증**: 사용자

### D.1.6 "개구부 모드" 토글 ON
- **입력**: 팔레트 개구부 모드 ON
- **경유**: `DefineTab._on_opening_mode_toggle(True)` → `canvas.set_edit_mode('opening')`
- **결과 (화면)**: 2D 캔버스 개구부 모드 전환
- **검증**: 사용자

### D.1.7 "개구부 추가" 버튼
- **입력**: 팔레트 "개구부 추가" 클릭
- **경유**: `_on_opening_add()` → `canvas.start_opening_add()`
- **결과 (화면)**: 개구부 추가 모드 진입 (벽 클릭으로 개구부 배치)
- **검증**: 사용자

### D.1.8 "벽 배치(내벽)" 버튼
- **입력**: 팔레트 "벽 배치" 클릭
- **경유**: `_on_wall_place()` → `_palette.clear_special_modes()` + `canvas.set_edit_mode('component')` + `canvas.handle_palette_select(INTERIOR_WALL)`
- **결과 (모델)**: 직접 변경 없음
- **결과 (화면)**: 다른 특수 모드 해제 + 컴포넌트 모드 + 내벽 배치 미리보기
- **검증**: AI + 사용자

### D.1.9 "코어 슬래브 재생성" 버튼
- **입력**: 팔레트 코어 슬래브 재생성 클릭
- **경유**: `controller.regenerate_all_core_slabs()`
- **결과 (모델)**: 코어 영역에 슬래브 부재 재생성 (부재 추가/교체)
- **결과 (화면)**: 3D·2D 캔버스에 슬래브 메쉬 갱신
- **검증**: AI (Scene.components 비교) + 사용자

## D.2 중앙 3D 캔버스 (정의 탭 자체 Viewer3D)

### D.2.1 좌클릭 (의도적 비활성)
- **입력**: 3D 캔버스 좌클릭
- **경유**: `DefineTab.eventFilter` 의 `MouseButtonPress` → `event.button() == LeftButton` 분기 → `return True` (무시)
- **결과**: 아무 동작 없음
- **검증**: AI

### D.2.2 중클릭 드래그 (카메라 — C.1 참조)
- → 공통 카메라 시나리오 C.1 로 이동

### D.2.3 우클릭
- **입력**: 3D 캔버스 우클릭
- **경유**: `DefineTab.eventFilter` → `controller.on_qt_mouse_press(RightButton, pos)`
- **결과**: 컨트롤러의 우클릭 동작 (모드별로 다름 — 컴포넌트 모드면 미리보기 회전 등)
- **검증**: 사용자 (컨트롤러 정독 후 보강 — 다음 턴)

### D.2.4 키 입력 → 2D 캔버스로 라우팅
- **입력**: 3D 캔버스 포커스 상태에서 키 누름
- **경유**: `DefineTab.eventFilter` 의 `KeyPress` → `F5/F6 면 무시` + 그 외 → `self._f5_panel.canvas.keyPressEvent(event)` 로 위임
- **결과**: 2D 캔버스가 키 입력 받음 (A 섹션에서 처리)
- **검증**: AI

### D.2.5 마우스 무브 (정의 탭은 무시)
- **입력**: 3D 캔버스 위 마우스 이동
- **경유**: `eventFilter` 의 `MouseMove` → `return False`
- **결과**: 처리 없음 (vispy 가 받지만 사용 안 함)
- **검증**: AI

### D.2.6 중클릭 릴리스 후 카메라 갱신
- **입력**: 중클릭 드래그 종료
- **경유**: `eventFilter` 의 `MouseButtonRelease` + `MiddleButton` → `controller.refresh_after_camera()`
- **결과 (화면)**: 카메라 종료 후 스냅 가이드·라벨 위치 갱신
- **검증**: 사용자

## D.5 우측 부재 속성 패널 (DesignPropertiesPanel)

### D.5.1 단면 타입 변경 (각형강관 / H형강)
- **입력**: 단면 타입 라디오/콤보 변경

## D.6 우측 실 속성 패널 (RoomPropertiesPanel)

### D.6.1 캔버스 실 선택 → 패널 전환
- **입력**: 2D 캔버스 실 영역 클릭
- **경유**: `AlignmentCanvas.room_selection_changed(int)` → `DefineTab._on_room_selected(room_id)` → `_show_room_props(room)` → `_props.setVisible(False)` + `_room_props.setVisible(True)` + `_room_props.set_room(room)`
- **결과 (화면)**: 우측이 실 속성 패널로 전환 + 해당 실 데이터 표시
- **검증**: AI + 사용자

### D.6.2 실 속성 편집 (종류·적재하중·마감하중)
- **입력**: 실 속성 입력 변경 후 확정
- **경유**: `RoomPropertiesPanel.room_edited(int, str, float, float)` → `_on_room_edited` → `controller._update_room(...)`
- **결과 (모델)**: Scene.rooms[id] 속성 변경
- **결과 (화면)**: 3D 실 색면 갱신
- **검증**: AI (rooms dict 비교) + 사용자

### D.6.3 실 삭제 버튼
- **입력**: 실 삭제 버튼 클릭
- **경유**: `RoomPropertiesPanel.room_delete_requested(int)` → `_on_room_delete` → `controller._delete_room` + `canvas.clear_room_selection()` + `_show_room_props(None)`
- **결과 (모델)**: Scene.rooms 에서 제거
- **결과 (화면)**: 3D 실 색면 제거 + 실 속성 패널 숨김 + 부재 속성 패널 복귀
- **검증**: AI + 사용자

## D.7 우측 정의 라이브러리

### D.7.1 정의 저장
- **입력**: 이름 입력 + "저장" 버튼
- **경유**: `_on_lib_save()` → 이름·components 검증 → `library.add_from_scene(name, scene, n_floors=1)` → `_refresh_lib_list()` → `dim_panel.set_mode_text(...)`
- **결과 (모델)**: 정의 라이브러리에 항목 추가
- **결과 (화면)**: 목록에 새 항목 + 치수 패널 상태 텍스트 변경
- **예외 경로**: 이름 없으면 안내 메시지박스 / 빈 작업공간이면 안내 / 저장 실패 시 경고
- **검증**: AI + 사용자

### D.7.2 정의 불러오기
- **입력**: 목록 선택 + "불러오기" 버튼
- **경유**: `_on_lib_load()` → `library.get(name).to_scene()` → `_load_scene_into_workspace(scene, n_floors)`
- **결과 (모델)**: 작업공간 Scene 교체 (components·rooms·joint_overrides 모두 재등록)
- **결과 (화면)**: 3D·2D 캔버스 전체 갱신 + 이름 입력란 갱신
- **예외**: 항목 미선택 시 안내 / 변환 실패 시 경고
- **검증**: AI (Scene dict 비교) + 사용자

### D.7.3 새로 만들기
- **입력**: "새로" 버튼
- **경유**: `_on_lib_new()` → `_clear_workspace()` + 이름란 비움
- **결과 (모델)**: components·rooms·undo 모두 비움
- **결과 (화면)**: 3D·2D 전체 비움
- **검증**: AI + 사용자

### D.7.4 정의 삭제
- **입력**: 목록 선택 + "삭제" 버튼
- **경유**: `_on_lib_delete()` → `library.remove(name)` → `_refresh_lib_list()`
- **결과 (모델)**: 라이브러리에서 제거
- **결과 (화면)**: 목록 갱신
- **검증**: AI

### D.7.5 건물 파일에서 불러오기
- **입력**: "건물 파일에서 불러오기" 버튼
- **경유**: `_on_lib_load_from_file()` → `QFileDialog` → `load_scene(path)` → `_load_scene_into_workspace(scene, n_floors)`
- **결과 (모델)**: scene.json 파일 내용을 작업공간 Scene 으로
- **결과 (화면)**: 3D·2D 전체 갱신 + 치수 패널 상태 텍스트
- **검증**: AI + 사용자

### D.7.6 정의 목록 항목 선택 (단순 표시)
- **입력**: 목록 항목 클릭
- **경유**: `QListWidget.currentRow()` 변경 (시그널 connect 없음)
- **결과**: 다음 "불러오기/삭제" 버튼 동작의 대상 결정 (자체 동작 없음)
- **검증**: AI

# 2. 배치 탭 (P) — 정의 탭과 차이점 위주

배치 탭은 *MainWindow 인스턴스의 공유 Viewer3D/Controller/Scene* 을 사용. 정의 탭은 자체 인스턴스를 가짐 (D.1~D.8 와 *내부 동작 동일*). 본 섹션은 *차이점* 만 enumerate.

## P.1 좌측 팔레트 — 타입 선택 인터셉트

### P.1.1 모듈 타입 1~9 클릭 (정의 라이브러리 존재 시 프롬프트)
- **입력**: 팔레트 타입 버튼 1~9 클릭
- **경유**: `MainWindow._on_design_type_select(comp_type)` 인터셉트 (`controller._type_select_intercept` 로 주입) — 정의 라이브러리에 같은 타입의 저장된 정의가 있으면 *"새로 만들기 / 가져오기"* 프롬프트 다이얼로그
  - "새로 만들기" → 기존 `Controller._start_placement(comp_type)` 흐름 (D.1.1 와 동일)
  - "가져오기" → `AlignmentCanvas.begin_import_preview(pivots, footprints, room_polys)` — A.4 시나리오 진입
- **결과**: 분기에 따라 일반 배치 미리보기 또는 정의 그룹 미리보기
- **검증**: AI (분기 결정 dict) + 사용자 (다이얼로그 표시)

### P.1.2 좌측 팔레트 나머지 버튼 (실/개구부/벽/코어 슬래브)
- D.1.3 ~ D.1.9 와 *동일*. 본 탭 전용 차이 없음.

## P.2 중앙 3D 캔버스 — 좌클릭 활성

### P.2.1 3D 캔버스 좌클릭 → 정의 탭과 달리 *비활성*
- **입력**: 디자인 탭에서 3D 캔버스 좌클릭
- **경유**: `MainWindow.eventFilter` 의 `MouseButtonPress` → `_is_design_tab() and LeftButton` → `return True` (무시)
- **결과**: 부재 선택·배치 모두 2D 캔버스에서만 수행. 3D 는 *시점·뷰*
- **주의**: 정의 탭과 *동일한* 정책. 즉 두 탭 모두 3D 좌클릭은 무효.

# 3. 2D 캔버스 공통 동작 (A) — AlignmentCanvas + AlignmentDockPanel

정의 탭·배치 탭 양쪽에서 *동일하게* 사용되는 2D 평면뷰. 정의 탭은 상단 SpinBox 만 숨김.
`AlignmentCanvas` 는 다중 상태기계 — 편집 모드(component/room/opening) × 정렬 상태(IDLE/SELECTED/DIRECTION/REFERENCE/DEPENDENCY_PICK) × 진행 중 미리보기(F5/실/개구부/정의가져오기).

## A.-1 캔버스 그리기 (모든 상태 변경 후 자동 호출)

### A.-1.1 paintEvent — AlignmentCanvasPaintMixin.paintEvent
- **트리거**: `self.update()` 호출 후 Qt 가 자동 호출 (모든 모드 전환·선택·미리보기 갱신 후)
- **경유**: `AlignmentCanvasPaintMixin.paintEvent(event)` → QPainter 로 부재 사각형·실 폴리곤·선택 하이라이트·정렬 오차 빨강·노란 모서리·녹색 기준선·고스트 미리보기·스냅 마커·고무줄선·도움말 그리기
- **결과 (화면)**: 위 시나리오들의 *모든 화면 결과* 의 실제 렌더링이 여기서 일어남
- **마이그레이션 핵심**: vispy `SceneCanvas` + QPainter 혼합 그리기 전체를 three.js 의 OrthographicCamera + 라인/메쉬·오버레이 SVG/Canvas2D 로 *완전 대응 이관* 필요
- **검증**: 사용자 (시각 일치)

## A.0 캔버스 좌표·뷰포트

### A.0.1 초기 자동 fit (resizeEvent 1회)
- **입력**: 첫 resize 이벤트
- **경유**: `AlignmentCanvas.resizeEvent` → `_auto_fit_done==False` 면 `_auto_fit()` → 모든 가시 부재 bbox + 500mm 마진으로 zoom·pan 산출
- **결과**: 캔버스 좌표계가 부재 전체 + 여유 보이도록 자동 맞춤
- **검증**: AI (`_zoom`, `_pan_x`, `_pan_y` 값 비교)

### A.0.2 마우스 휠 줌 (커서 기준)
- **입력**: 캔버스 위 휠
- **경유**: `wheelEvent` → factor = 1.15 (위) / 1/1.15 (아래) → `_zoom *= factor` → 커서 위치가 줌 고정점 되도록 `_pan_x/y` 재계산
- **결과 (모델)**: 변경 없음
- **결과 (화면)**: 커서 위치를 중심으로 확대/축소
- **검증**: 사용자 (커서 추적)

### A.0.3 중클릭 드래그 팬
- **입력**: 캔버스 중클릭 누르고 드래그
- **경유**: `mousePressEvent` MiddleButton → `_panning=True` + 시작점 저장 / `mouseMoveEvent` 가 `_pan_x/y` 갱신 / `mouseReleaseEvent` MiddleButton → `_panning=False`
- **결과 (화면)**: 평면 시점 이동
- **검증**: 사용자

## A.1 컴포넌트 모드 — 부재 선택·정렬·삭제·이동·복사

### A.1.1 빈 영역 좌클릭 → 선택 해제 + reset_state
- **입력**: 빈 영역(부재 없는 곳) 좌클릭
- **경유**: `mousePressEvent` → `_hit_test_component` 결과 0 → `reset_state()` → 상태 IDLE + `selection_changed.emit(-1)`
- **결과 (화면)**: 모든 하이라이트 제거, 우측 디자인 속성 패널 초기화
- **검증**: AI + 사용자

### A.1.2 부재 클릭 → SELECTED
- **입력**: 부재 영역 좌클릭
- **경유**: `_hit_test_component` > 0 → `_selected_id=hit` + `_state=SELECTED` + 방향·기준 해제 + `selection_changed.emit(hit)`
- **결과 (화면)**: 선택 부재 4 모서리 파란 하이라이트 + 정렬 오차(≤100mm, 정확 20 제외) 다른 부재 빨강 + 거리 표시 + 우측 속성 패널 갱신
- **검증**: AI (선택 ID) + 사용자 (하이라이트 시각)

### A.1.3 SELECTED + X / Y 키 → DIRECTION
- **입력**: 선택 상태에서 X 또는 Y 키
- **경유**: `keyPressEvent` → `_direction='X'|'Y'` + `_state=DIRECTION`
- **결과 (화면)**: 해당 방향의 선택 부재 모서리 2개 노란색 표시

### A.1.4 DIRECTION + 노란 모서리 클릭 → REFERENCE
- **입력**: 방향 표시된 노란 모서리 클릭

- **결과 (화면)**: 기준 모서리 녹색 확정 + 대상 부재 호버 가능

### A.1.5 REFERENCE + hover + 1~5 키 → 스냅 이동
- **입력**: 다른 부재 호버 중 1·2·3·4·5 키
- **경유**: `keyPressEvent` 의 우선순위 1) → `_apply_snap(key)` → delta 계산 후 `move_requested.emit(comp_id, axis, delta)` → `AlignmentDockPanel._apply_move` 가 그룹 통째 이동 + viewer/snap 재등록 → `reset_state()`

- **결과 (모델)**: 다수 components + rooms 한꺼번에 등록
- **검증**: AI + 사용자

## A.5 AlignmentDockPanel — 상단 컨트롤

### A.5.1 층수 SpinBox 변경
- **입력**: 층수 SpinBox 값 변경 (스크롤·키 입력 모두)
- **경유**: `_on_floors_changed(n)` → `_snap_to_three(n)` → 3 배수 아니면 SpinBox 보정 + 로그 → `floors_changed.emit(snapped)`
- **수신**: controller 가 `_on_floors_changed` 슬롯에서 다층 그룹 재생성
- **결과 (모델)**: 모든 그룹의 다층 복제 갱신
- **결과 (화면)**: 3D·2D 모두 갱신
- **제약**: 3~24, 3 배수만 (수직 3층 모듈과 단층 모듈 혼용 위해)
- **검증**: AI + 사용자

### A.5.2 외부 set_floors 호출 (정의 불러오기 등)
- **입력**: `_load_scene_into_workspace` 등에서 `f5_panel.set_floors(n)`
- **경유**: `_snap_to_three` 적용 + `blockSignals` 로 emit 차단 (또는 emit=True 옵션)
- **결과**: SpinBox 값만 갱신, controller 재생성 트리거 없음 (불러오기는 별도로 부재 등록함)
- **검증**: AI

### A.5.3 저장 버튼
- **입력**: 상단 "저장" 클릭
- **경유**: `save_requested.emit()` → controller 가 scene.json 저장 다이얼로그
- **검증**: AI (시그널 emit 카운트) + 사용자

### A.5.4 불러오기 버튼
- **입력**: 상단 "불러오기" 클릭
- **경유**: `load_requested.emit()` → controller 가 scene.json 불러오기 다이얼로그
- **검증**: AI + 사용자

### A.5.5 set_floors_control_visible(False) — 정의 탭 전용
- **입력**: 정의 탭이 생성 시 호출
- **경유**: 라벨·SpinBox·단위 라벨 3개 setVisible(False)
- **결과**: 정의 탭에서 층수 컨트롤 보이지 않음 (단일층 고정)
- **검증**: AI

### A.5.6 _apply_move — move_requested 수신 처리
- **입력**: AlignmentCanvas 의 `move_requested.emit(comp_id, axis, delta)`
- **경유**: `_apply_move(comp_id, axis, delta)` → `translate_group(scene, gid, delta_vec)` → affected 부재 viewer/snap 재등록 + 새로 생성된 코어 슬래브 추가 + 상태바 갱신
- **결과 (모델)**: 그룹 부재 모두 axis 방향으로 이동 + sub_components 재생성
- **결과 (화면)**: 3D·2D 모두 갱신
- **검증**: AI (Scene.components dict 비교, mm 정밀도) + 사용자

# 4. 카메라/뷰포트 공통 (C)

### C.1 카메라 회전 (중클릭 + 좌우 드래그)
- **입력**: 3D 캔버스 중클릭 드래그 (Shift 없음)
- **경유**: `CustomCamera.viewbox_mouse_event` → mouse_press(button=3) → `_drag_mode = 'rotate'` → mouse_move 시 azimuth·elevation 갱신 → mouse_release 시 종료
- **결과 (모델)**: 카메라 azimuth·elevation 변화
- **결과 (화면)**: 3D 뷰 회전
- **검증**: 사용자 (회전 중심·감도 자연스러움)

### C.2 카메라 팬 (Shift + 중클릭 드래그)
- **입력**: Shift 누른 채 중클릭 드래그
- **경유**: 같은 핸들러 + `_drag_mode = 'pan'` → center 좌표 갱신
- **결과 (화면)**: 카메라 중심 이동
- **검증**: 사용자

### C.3 카메라 줌 (휠)
- **입력**: 3D 캔버스 위 휠
- **경유**: `viewbox_mouse_event` → `mouse_wheel` → `_zoom_toward_cursor(event)` (커서 방향 줌)
- **결과**: 카메라 distance 변화, 커서 위치가 줌 기준
- **검증**: 사용자 (커서 추적 정확도)

### C.4 카메라 종료 후 갱신
- **입력**: 중클릭 릴리스
- **경유**: `eventFilter` 의 `MouseButtonRelease` → `controller.refresh_after_camera()`
- **결과 (화면)**: 스냅 가이드·라벨·아이콘 위치 카메라에 맞춰 재계산
- **검증**: 사용자
