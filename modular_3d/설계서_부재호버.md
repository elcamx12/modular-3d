# 부재 단위 호버·클릭 정보창 시스템 — 설계서

생성: 2026-05-18
대상: `modular_3d/` 의 F6 구조해석(ops) 뷰

---

## 0. 한눈에 보기

F6 구조해석 뷰에서 마우스를 부재 위에 올리면 해당 부재가 색으로
강조되고 마우스 옆에 정보창이 떠 부재 이름·하중값·AFD/SFD/BMD
미니 그래프를 보여 준다. 부재를 클릭하면 정보창이 고정되고,
다른 부재를 클릭하면 추가 정보창이 떠서 비교가 가능하다. 동시에
최대 5 개 까지 떠 있을 수 있고, 새 부재 클릭 시 가장 오래된
정보창이 자동으로 닫힌다. 케이스(D+L / Ex / Ey / Wx / Wy) 콤보박스
하나로 모든 떠 있는 정보창이 일괄 갱신된다.

기존 컴포넌트 단위 빨간 테두리 강조(편집·해석 모드 양쪽 모두)
는 제거된다 — 마우스 위치 전달 결함으로 어차피 잘 동작하지 않고,
부재 단위 호버가 대체한다.

## 1. 사용자 결정 요약 (라운드 1~4)

### A. 기존 빨간 강조 제거
- 증상: 클릭 위치에서 멀리 떨어진 다른 컴포넌트가 잡힘 (좌표 오프셋).
- 처리: 별도 디버깅 없이 새 부재 호버 시스템으로 자연 소멸 시킴.
- 범위: 편집 모드를 포함해 컴포넌트 빨간 테두리 강조 시스템을
  **전부 제거**. 편집 모드에서도 클릭이 잘 안 들으므로 필요 없다.

### B. 새 시스템 작동 범위 / 표시 내용
- **F6 구조해석 뷰 활성 시에만 동작**. 일반 편집 모드는 호버 안 받음.
- 부재 이름: 트리에서 만든 한국어 위계 풀이름 — `"1층 a모듈 기둥 #123"`.
- 표시 항목: 길이 L, 단면 명칭, 응력비, kind(beam/column),
  양단 단면력 N / V / M.
- 응력비: 현재 패널 라디오(1종/2종/3종) 선택 기준.
- 표시 케이스: 한 번에 하나. 케이스 전환은 정보창 내부 탭이 아니라
  **기존 하중조합 콤보박스 하나로 모든 떠 있는 창이 일괄 갱신**.

### C. 정보창 동작
- 위치: 처음엔 마우스 커서 옆에 등장. 클릭 고정 후엔 그 자리에 멈춤.
  사용자가 드래그로 이동 가능, **3D 렌더 영역 밖으로는 못 나감**.
- 호버 해제: 부재에서 마우스가 벗어나면 정보창은 **즉시 사라짐**
  (디버깅 편의를 위해 지연 없음).
- 클릭 고정 해제: ① 정보창 × 닫기 버튼, ② ESC 키 (모든 팝업 동시
  닫기), ③ 빈 공간 클릭으로는 해제 안 함.
- 새 부재 클릭: 기존 창은 유지하고 **새 창이 추가**됨 (비교용).
- 같은 부재 재클릭: 기존 창이 이미 떠 있으면 **그대로 유지**.
- 다중 표시 한도: 최대 5 개. 6 번째를 띄우면 가장 먼저 켠 정보창부터
  순차 닫힘 (FIFO).
- 새 창 초기 위치: 클릭한 마우스 옆. 기존 창과 거의 겹치면 캐스케이드
  (살짝 옆/아래로 비켜서 등장).

### D. 호버 탐지
- 마우스에서 부재 라인까지의 **화면(스크린) 거리** 8~10 px 이내면 호버.
- 화면 사영 후 가장 가까운 한 부재만.
- 와이어프레임 뷰라 깊이 가려짐은 무시.
- 분절된 부재(예: 수직 3 층 모듈 기둥)는 클릭한 그 분절 하나만 잡힘.

### E. 강조선 색 정책 (다중 팝업 ↔ 강조선 매칭)
- 팝업이 떠 있는 부재마다 **서로 다른 색**으로 강조선을 그려, 정보창과
  강조선을 시각적으로 묶음. 정보창 외곽선이 같은 색.
- 호버 중(아직 클릭 안 한) 임시 강조: **다음에 배정될 색을 미리 보여줌**
  — 클릭하면 그 색이 그대로 고정되어 자연스러운 연결.
- 색 팔레트(5 색): 기존 프로그램이 안 쓰는 색만 사용. 응력비 5 단계
  (파/하/초/주/빨), 부재 트리 강조(파랑), 빨간 박스(폐기 예정),
  노란 스냅 마커, 보라 코어를 피한다.
  - 후보: **시안(#00C8C8) / 마젠타(#D000C0) / 라임(#A8D000) /
    티얼(#1FB7A0) / 다크오렌지(#D87A00)**. 검토 시 변경 가능.

### F. 부재 분포력 데이터
- OpenSees 에서 부재마다 **5 station 점**(양단 + 1/4, 중앙, 3/4)
  단면력을 추출.
- 추출 시점: **F6 풀이 직후 한 번에 모두**(부재 × 케이스 5 × station 5)
  뽑아 캐시. 부재 클릭 시 즉시 반응.
- 그래프 단위: AFD = kN, SFD = kN, BMD = kN·m.
- BMD 부호: **처짐 방향(아래) = 양수** (구조설계 관례).
- 축력 부호: OpenSees 규약과 구조설계 관례 모두 **인장 +, 압축 −** 동일,
  그대로 사용.

### G. 트리 ↔ 정보창 연동
- 트리에서 **부재 행(잎)** 을 클릭하면 정보창이 등장한다.
  등장 위치는 **3D 렌더 영역의 우하단 모서리**, 이미 다른 창이 점유
  중이면 캐스케이드.
- 트리에서 **그룹 노드**(모듈/층/역할 묶음) 를 클릭한 경우는 정보창이
  **뜨지 않는다** — 다 띄우면 화면이 모두 가려진다. 그룹 클릭 시 기존
  파란 다중 부재 강조만 동작.

### H. 정보창 시각 스타일
- 배경: **불투명 흰색**.
- 폰트: 본문과 같은 9 pt.
- 모서리: 살짝 둥근 모서리(과하지 않게, 6 px 정도).
- 외곽선: 해당 정보창에 배정된 색(2 ~ 3 px 두께).

### I. 페이즈 진행 우선순위
- 클로드 판단대로. 잘게 나눌 것.

### J. 설계서 파일
- 경로: `my_project/modular_3d/설계서_부재호버.md` (이 파일).
- 단일 파일에 모든 페이즈 섹션 분리.
- 페이즈 섹션 구성: 사용자 결정 요지(작업 내용에 자연스럽게 녹임) /
  작업 범위 / 변경 파일 / 변경 함수 / 작업 내용(코딩 plan 형식).
- 페이즈 완료 후 복기는 클로드 머릿속에서만, md 에는 적지 않음.

## 2. 페이즈 분할 (17 단계)

각 페이즈는 변경 파일·함수가 1 ~ 3 개 수준으로 작아야 한다. 한 페이즈
끝나면 import·실행 검증 후 다음으로 넘어간다. 페이즈별 작업 시작 전
이 md 파일을 다시 읽고, 코드 작성 후 다시 대조한다.

| # | 제목 | 핵심 결과물 |
|---|------|------------|
| 0 | 기존 컴포넌트 빨간 강조 제거 | 편집·해석 모드 양쪽에서 `_pick_component` 류 호출 + `_selection_box` 비주얼 제거 |
| 1 | 부재 화면거리 픽킹 인프라 | F6 뷰 활성 시 마우스 좌표 → 가장 가까운 부재 mid 반환 함수 |
| 2 | 호버 강조 표시 | 호버된 부재 1 개를 임시 색으로 강조, 호버 해제 시 색 제거 |
| 3 | 정보창 위젯 골격 | 빈 흰 패널(둥근 모서리, 외곽선) — 마우스 옆 등장, 호버 해제 시 즉시 사라짐 |
| 4 | 정보창 텍스트 표시 | 이름·L·단면·응력비·kind·양단 N/V/M 6 행 |
| 5 | 분포력 station 5점 추출/캐시 | F6 풀이 직후 모든 부재 × 5 케이스 × 5 station 캐시 |
| 6 | AFD 미니 그래프 | 정보창에 작은 축력 분포도 추가 |
| 7 | SFD 미니 그래프 | 전단력 분포도 추가 |
| 8 | BMD 미니 그래프 | 휨모멘트 분포도(처짐 방향 양) 추가 |
| 9 | 클릭 고정 + 색 팔레트 | 클릭하면 그 자리에 멈춤, 5 색 중 한 자리 점유, 강조선 색 매칭 |
| 10 | 정보창 드래그 이동 | 사용자가 끌어서 위치 변경, 3D 영역 밖 클램프 |
| 11 | 정보창 × 닫기 버튼 | 헤더 우측 × 클릭 → 해당 창 + 강조선 동시 제거 |
| 12 | 다중 정보창 + FIFO | 최대 5 개, 6 번째 클릭 시 가장 오래된 것 자동 제거. 같은 부재 재클릭은 새로 안 띄움. 캐스케이드 등장. |
| 13 | 호버 색 = 다음 배정 색 미리보기 | 호버 임시 색을 "다음 클릭 시 받을 색" 으로 변경 |
| 14 | ESC 모든 팝업 닫기 | 전역 단축키, 5 개 동시 닫힘 |
| 15 | 케이스 콤보박스 일괄 갱신 | 케이스 바꾸면 떠 있는 모든 정보창의 수치 + 그래프 다시 그림 |
| 16 | 트리 잎 클릭 → 우하단 등장 | 부재 행 클릭 시 정보창이 3D 영역 우하단에 등장(캐스케이드) |
| 17 | 트리 그룹 클릭은 정보창 미생성 | 그룹 노드 클릭은 기존 다중 부재 강조만 동작 (정보창 X) |

## 3. 페이즈별 작업 계획

### Phase 0 — 기존 컴포넌트 빨간 강조 시스템 제거

기존에 사용자가 마우스로 컴포넌트를 클릭하면 빨간 테두리 박스가 뜨던
시스템은 좌표 오프셋 버그가 있어 제대로 동작하지 않는다. 편집 모드
포함해 어차피 잘 안 쓰이므로 전부 제거하고, 부재 단위 호버 시스템으로
대체한다.

- **작업 범위**:
  - `_pick_component()` / `_select_component()` / `_deselect()` 호출 경로 삭제 또는 비활성
  - 빨간 와이어프레임 박스 비주얼(`_selection_box` 및 `show_selection_box`) 제거
  - `_selected_comp_id` 상태 변수는 다른 곳(이동/복사 등)에서 참조하면 보존
- **변경 파일**:
  - `modular_3d/ui/controls.py`
  - `modular_3d/render/viewer.py`
- **변경 함수**:
  - `controls.on_qt_mouse_press` 의 IDLE/SELECTED 분기에서 `_pick_component` 호출 제거
  - `viewer.show_selection_box` / `hide_selection_box` 제거 또는 무력화
- **충돌 검토 필수**: 컴포넌트 선택 상태(`_selected_comp_id`) 가 사라지면
  영향 받을 수 있는 기능을 사전에 모두 식별해야 한다. 이동(M 키),
  복사(C 키), 삭제(Delete), F2/F3/F4 등 단축키 흐름, 도구창의 "선택된
  부재" 라벨, 자유도 토글 등 — 각각의 동작이 깨지지 않는지 검증한다.
  깨질 경우 빨간 박스만 제거하고 선택 상태 자체는 보존하는 절충도 고려.
- **검증**: F5 / F6 모두 켜고 마우스 클릭 시 빨간 박스가 더 이상 안
  나오는지 + 위 기능들이 그대로 동작하는지 확인

---

### Phase 1 — 부재 화면거리 픽킹 인프라

F6 ops 뷰가 활성일 때, 마우스 Qt 좌표 → 화면 사영 후 가장 가까운 부재
mid 를 반환하는 함수를 만든다. 픽셀 거리 8 px 이내인 부재만 인정.

- **작업 범위**:
  - vispy scene transform 으로 부재 양 끝점을 화면 좌표로 사영
  - 각 부재 선분에 대해 마우스 점-선분 거리(2D) 계산
  - 임계값 이내 최소 거리 부재 반환, 없으면 `None`
- **변경 파일**: `modular_3d/render/viewer.py`
- **변경 함수**: 신규 `pick_ops_member_at(mouse_xy, ops_model, am)`
- **검증**: 임시 콘솔 로그로 호버한 부재 mid 확인

---

### Phase 2 — 호버 강조 표시 (단일 임시 색)

Phase 1 의 픽킹 결과를 받아, 호버된 부재 1 개를 단일 임시 색으로
강조 표시. 호버 해제 시 색 제거. 아직 클릭 고정 없음, 정보창 없음.
이 단계에서 사용하는 임시 색은 단순한 회색 등 중립 색이고, Phase 13
에 이르러 "다음 클릭 시 받게 될 슬롯 색" 으로 교체된다 — 즉 호버 색은
점진적으로 의미가 풍부해지는 방향으로 두 단계에 걸쳐 정착한다.

- **작업 범위**:
  - F6 ops 뷰 활성 시 `on_qt_mouse_move` 분기 추가
  - 픽킹 결과 mid → 강조 비주얼(기존 `_member_highlight` 재사용 가능)
- **변경 파일**:
  - `modular_3d/render/viewer.py` (호버용 색 옵션)
  - `modular_3d/ui/controls_f6.py` 또는 `controls.py` (호버 콜백)
- **변경 함수**:
  - `viewer.highlight_ops_member` 색 인자 확장 또는 `highlight_ops_member_hover` 신규
  - 호버 이벤트 처리에서 호출
- **검증**: 마우스 이동 시 부재가 즉시 강조됐다가 떠나면 사라짐

---

### Phase 3 — 정보창 위젯 골격

빈 흰 패널(둥근 모서리, 외곽선) 을 띄운다. 마우스 옆에 등장, 호버
해제 시 즉시 사라짐. 내용은 아직 빈 칸.

- **작업 범위**:
  - `QWidget` 서브클래스 신설: `MemberInfoPopup`
  - 부모는 vispy 캔버스의 native widget — 캔버스 위 absolute 배치
  - 배경 흰색, 둥근 모서리(border-radius: 6px), 외곽선(나중에 색 배정)
  - 마우스 옆에서 약간 떨어진 offset 으로 표시
- **변경 파일**:
  - 신규 `modular_3d/ui/member_info_popup.py`
  - `modular_3d/ui/controls_f6.py` (호버 시 보임/숨김)
- **검증**: 호버 시 빈 패널이 마우스 옆에 따라 나타나고, 떠나면 사라짐

### Phase 4 — 정보창 텍스트 표시

이름(트리 위계 풀이름), L, 단면, 응력비(현 정책), kind, 양단 N/V/M.
응력비는 패널 라디오 1종/2종/3종 선택 기준. 라디오가 아직 한 번도
선택되지 않은 초기 상태(분석 패널 미열림 등) 의 폴백은 **1 종**.

- **작업 범위**:
  - 트리에서 사용한 한국어 위계 라벨 빌더를 공유 모듈로 분리 또는 재사용
  - 양단 단면력은 `MemberForce.f_i` / `f_j` 에서 추출, kN / kN·m 단위로 환산
  - 응력비는 `quantity_reports[정책].member_ratios[mid]` 사용
- **변경 파일**:
  - `modular_3d/ui/member_info_popup.py`
  - `modular_3d/ui/analysis_panel.py` (라벨 빌더 공유)
- **검증**: 호버한 부재의 텍스트가 정확히 표시되는지 (트리에 보이는 이름과 일치)

### Phase 5 — 분포력 station 5 점 추출 + 캐시

F6 풀이 직후 모든 부재 × 5 케이스 × 5 station 의 N / Vy / Vz / My / Mz
값을 OpenSees 에서 추출해 캐시. 정보창은 이 캐시만 읽는다.

- **작업 범위**:
  - 5 station 비율: 0.0 / 0.25 / 0.5 / 0.75 / 1.0
  - OpenSees 의 `sectionForce` 또는 element response 사용
  - `OpsResults` 에 새 필드 `member_stations: Dict[mid, np.ndarray(5, 6)]` 추가
- **변경 파일**: `modular_3d/analysis/ops_solver.py`
- **변경 함수**: 풀이 후처리 함수에 station 루프 추가
- **검증**: 임의 부재의 양단(0, 1)이 기존 `f_i`/`f_j` 와 일치하는지 확인
- **비용 주의**: 부재 수 × 5 케이스 × 5 station 만큼 OpenSees element
  response 호출이 발생한다. 풀이 직후 한 번이라 절대 시간은 작을
  것으로 예상되나, 측정 결과 크게 부담스럽다면 station 수를 줄이거나
  부재 클릭 시 lazy 추출로 전환하는 절충안을 재검토한다.

### Phase 9 — 클릭 고정 + 색 팔레트 + 강조선 매칭

부재를 클릭하면 정보창이 그 위치에 멈춤. 5 색 팔레트 중 한 자리를
점유하고, 정보창 외곽선 색 + 3D 강조선 색이 같은 색으로 매칭됨.

- **작업 범위**:
  - 색 팔레트 5 색 상수 정의 (시안 / 마젠타 / 라임 / 티얼 / 다크오렌지 후보)
  - 색 점유 상태 관리자 (FIFO 슬롯 5 개)
  - 클릭 이벤트 → 슬롯 할당 + 정보창 생성 + 강조선 추가
- **변경 파일**:
  - `modular_3d/ui/controls_f6.py` (상태 관리자)
  - `modular_3d/render/viewer.py` (다중 색 강조선)
  - `modular_3d/ui/member_info_popup.py` (외곽선 색 적용)
- **검증**: 2 부재 클릭 후 두 정보창과 강조선이 서로 다른 색

### Phase 12 — 다중 정보창 + FIFO

최대 5 개. 6 번째 클릭 시 가장 오래된 정보창 자동 닫힘. 같은 부재를
재클릭하면 기존 창 유지(새로 안 띄움). 새 창 초기 위치는 클릭한
마우스 옆, 기존 창과 거의 겹치면 살짝 옆/아래로 캐스케이드.

- **작업 범위**:
  - 떠 있는 팝업 리스트 관리자
  - 겹침 검출 — 새 팝업 사각형이 기존 팝업과 좌상단 50 px 이내면 캐스케이드
- **변경 파일**: `modular_3d/ui/controls_f6.py`

### Phase 15 — 케이스 콤보박스 일괄 갱신

분석 패널의 케이스 콤보박스(D+L / Ex / Ey / Wx / Wy) 가 바뀌면,

다시 그려짐. 각 창이 독립적으로 다른 케이스를 보여 주지는 않는다
(나중 포락선 기반 확장은 별개 작업).

- **변경 파일**:
  - `modular_3d/ui/analysis_panel.py` (`case_changed` 시그널은 이미 있음)
  - `modular_3d/ui/controls_f6.py` (시그널 핸들러에 팝업 갱신 추가)

### Phase 16 — 트리 잎 클릭 → 우하단 등장

트리 위계에서 부재 행(잎) 을 클릭하면 정보창이 **3D 캔버스 영역의
우하단 안쪽**에 등장한다. 우측 도킹 패널이 상황에 따라 좌측으로
커지므로 절대 픽셀 좌표로 고정할 수 없고, 캔버스 자체의 우하단 모서리
기준으로 상대 좌표(여백 ~12 px) 를 잡고 캔버스 리사이즈 이벤트에
재배치된다. 이미 다른 창이 우하단을 점유 중이면 Phase 12 와 동일한
50 px 캐스케이드 규칙을 적용. 3D 호버/클릭과 동일한 5 색 팔레트
슬롯 시스템을 공유한다.

- **변경 파일**:
  - `modular_3d/ui/analysis_panel.py` (`member_selected` 시그널 핸들러에 추가 동작 X — 기존 강조 유지)
  - `modular_3d/ui/controls_f6.py` (`_on_panel_member_selected` 에 정보창 생성 추가)

### Phase 17 — 트리 그룹 클릭은 정보창 미생성

트리에서 그룹 노드(모듈/층/역할 묶음) 를 클릭하면 정보창은 뜨지
않는다. 그룹 하나에 부재가 5 개를 초과할 수 있어 정보창 정책(최대 5)
과 충돌하기도 하고, 화면이 전부 가려지는 시각 부담도 크기 때문이다.
이 경우 기존의 다중 부재 파란 강조 시스템만 동작하면 충분하다.

- **변경 파일**: `modular_3d/ui/controls_f6.py` (`_on_panel_members_selected` 는 강조만)
- **검증**: 그룹 클릭 시 강조선만 늘어나고 정보창은 안 뜸

## 4. 페이즈 진행 규칙

1. 각 페이즈 시작 전 이 md 파일을 다시 읽는다.
2. 해당 페이즈의 작업 범위 안에서만 코드 작성.
3. 작성 후 이 md 파일의 해당 페이즈와 코드를 대조해 불일치를 찾는다.
4. 불일치가 있으면 사용자에게 보고하고 결정 받기.
5. 클로드 머릿속으로 복기 (md 에는 기록하지 않음).
6. 다음 페이즈로 넘어가기.
