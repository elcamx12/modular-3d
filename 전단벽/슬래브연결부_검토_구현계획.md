# 슬래브-벽체 격막 연결부 전단강도 검토 — 구현계획 (#6 파생과제)

모델링지침 2025 제8장 식 8-1~8-6. 격막하중(수요 Vu) ≤ 연결부 전단강도(강도 Vn)
힘지배거동 안전성 검토. 슬래브 철근(수집재·다우얼)의 지침상 정확한 쓰임.

## 정석 식 (이미지 렌더로 확보)
- Vn = min(Vn_a, Vn_b)
  - Vn_a = T_col1 + 0.5·T_dw·cotθ + C_cb   (8-1a 지압 전)
  - Vn_b = T_col1 + V_dw                     (8-1b 지압 후)
  - T_col1 = fy·As,col1 / T_dw = min(fy·As,dw, Cds·sinθ) / C_cb = 0.85·βn·fck,dw·hs·bw
  - Cds = 0.85·βs·fck·hs·lw·sinθ / V_dw = min(μ·fy·As,dw, 0.2·fck·Ac,sw, (3.3+0.08·fck)·Ac,sw, 11·Ac,sw)
  - Ac,sw=hs·lw, βn=βs=0.6, μ=1.0, θ=45°

## 정석 전환 설계
- 강도 Vn = 처음부터 정석. 수요 Vu = **주입 구조**(check_connection 이 Vu 받음).
  지금 간이(코어 총 횡력), 향후 #2(코어 층별 결과) 완성 시 Vu 만 층별 정밀치로 교체 → 정석.

## 단계
- A. **강도 함수** — ★완료(2026-06-29). `analysis/slab_connection.py`:
  `connection_shear_strength(...)`(식 8-1~8-6, ConnectionStrength) + `check_connection(Vu, ...)`
  (φVn 대비 비율·안전). 손계산 100% 일치(Vn=1200kN 예제 전 항 검증).
- B. **수요 Vu 산정(간이)** — ★완료(2026-06-29). `core_lateral_demand(am, scene, base_reactions,
  direction)` — 코어 그룹별 베이스 수평반력 합. 검증: A최신 X방향 그룹5=274kN·그룹6=342kN,
  코어 합 617kN이 전체 횡력 627kN 의 98%(코어가 주저항). z최소 코너만 식별(적층 위층 제외).
- C. **슬래브 철근 입력 UI** — ★완료(2026-06-29). `CORE_REBAR_DEFAULT` 에 슬래브 키 3개
  추가(slab_collector_area·slab_dowel_area·slab_fck, 기본 0·0·27). `design_props_panel` 코어
  철근 섹션에 '슬래브 연결부 철근(지침 8장)' 입력 3칸 + 배근 면적 다이얼로그(RebarCalcDialog
  area_mode 확장 — area() 반환). 슬래브 fck 는 벽 fck 와 독립(식 요구). 검증: 컴파일·왕복·지문
  감지·골든 통과. 화면 동작은 사용자 직접 확인.
- D. **검토 결과 표시 + 통합 검증** — 진행 예정.
  - D-1 검토 로직 — ★완료(2026-06-29). `check_core_group_connections(am, scene, base_reactions,
    direction, phi)` → {gid: {Vu, sumVn, phiVn, ratio, safe, n_wall, governs}}. 검증: 미입력(철근0)
    → 위험(8-1b, Vn=0), 충분 → 안전(비율 0.02~0.03). 골든 통과.
  - D-2 표시 UI — ★완료(2026-06-29). 사용자 결정: 구조해석 결과 패널 통합 + 해석 시 자동.
    analysis_panel 부재력 탭 위에 `_conn_table`(코어·Vu·φΣVn·비율·판정) 추가, `populate_ops`
    에서 `_fill_core_connection_table()` 자동 호출(지진 Ex 우선 Ey, base_reactions 기준).
    안전 녹색·위험 빨강. 코어 없으면 숨김. 컴파일·골든 통과. 화면 동작은 사용자 직접 확인.

## ★파생과제(슬래브-벽체 연결부 검토) 전체 완료(2026-06-29)
강도(정석 식 8-1~8-6)·수요(코어 그룹별 베이스 반력)·슬래브 철근 입력 UI·검토 결과 표시 완성.
정석 전환: 수요만 #2(코어 층별 결과) 완성 시 층별 정밀치로 교체하면 지침 층별 연결부 검토 완성.
**남은 확인: UI 화면 동작(코어슬래브 클릭→슬래브 철근 칸·배근, 해석→검토 표) 사용자 직접 실행.**

## 비고
- 형상(hs 슬래브두께, bw 벽두께, lw 벽길이)은 모델에서 자동. fy·fck 는 코어 입력 재사용 or 슬래브 별도.
- 지침 (5)항 조정(벽 내부/모서리/개구부/돌출)은 우선 외곽경계 기본식(8-1)으로, 조정은 후속.
