# 코어 철근 사용자입력 — 구현계획 (후속과제 #6)

코어벽·슬래브 철근을 사용자가 평면설계 탭에서 입력해 해석에 반영한다.
지침(모델링지침 2025 제8장) 검토 결과를 반영한 확정 방향:

## 확정 방향
- **코어벽 철근** → fiber 비선형에 직접 반영(역량곡선 변화). [이번 작업]
- **코어 슬래브 철근** → 벽체–슬래브 연결부 전단강도 검토(지침 식 8-1~8-6, 힘지배 안전성). [별도 후속]
- **슬래브 격막** = 강체 유지(지침 "통상" 기본). 비강체(유효강성 25%)는 향후 옵션
  — 가장자리/돌출 판정은 정성적이라 자동화하지 않음.

## 입력 사양 (사용자 확정)
- **단위**: 코어 그룹(group_id)별 1 세트. 전 층 자동 적용.
- **UI**: 코어 **슬래브** 선택 → 우측 속성 패널에서 그 그룹의 코어벽 철근 입력.
- **항목**: 경계요소 철근비 ρ_be, 웹 철근비 ρ_web, 콘크리트 강도 fck, 철근 항복강도 fy.
  - 경계요소 길이(lbe)·fiber 분할 수는 자동(현재 로직 유지).
- **형식**: 철근비(%) 직접 입력 / 배근(개수-직경) 입력 후 철근비 자동 환산 — **둘 다 지원**.
- **미설정 그룹**: 현재 기본값(경계 2%·웹 0.4%·fck27·SD400) 사용 → 기존 저장 파일 호환.

## 데이터 저장 위치
- `Scene.core_rebar: Dict[group_id, {rho_boundary, rho_web, fck, fy}]`
  — joint_overrides 와 같은 Scene 레벨 컬렉션. 그룹당 1 개라 다층 동기화 불필요.

## 비고
- 배근 환산: 철근비 = 철근 총단면적 / 콘크리트 면적. 경계요소는 (두께 t × lbe),
  웹은 (두께 t × 웹길이) 기준. 환산은 UI(Phase 3)에서, 저장은 환산된 ρ 로.
