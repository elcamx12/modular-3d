## 4. 철근 — Menegotto-Pinto (Steel02 / SteelMPF)
- 공통: E0 = 200 GPa, R0 = 20, cR1(a1) = 18.5, cR2(a2) = 0.15
- **#3 경계철근** (db=9.53mm): 압축 fy=434 MPa·b=0.02 / 인장 fy=395 MPa·b=0.0185
- **#2 웹철근** (db=6.35mm): 압축 fy=448 MPa·b=0.02 / 인장 fy=336 MPa·b=0.035
  (인장값이 낮은 건 Belarbi-Hsu 인장강성 보정 반영분 — 단순화하면 압축값 fy로 통일 가능)

## 5. 전단
- 수평 전단스프링: 선형탄성 가정으로 시작(MVLEM 의 -matShear). 휨지배 벽이라 전단변형 기여 작음.

## 6. 축력
- 일정 축력 **0.10·Ag·f'c** (Ag = 1219×102 = 124,338 mm²; f'c=42.8 MPa → P ≈ 532 kN)
  ※ 보고서 본문 "approximately 0.10 Ag f'c". 실제 측정은 시험 중 변동.

## 7. 가력 프로토콜
- 변위제어 반복가력: drift 0.1% → 0.25% → 0.25%씩 1.0% → 1.5% → 1.0% → 0.5%씩 2.5% (총 20사이클)
- **우리 목표(Pushover)**: 위 반복 대신 **단조 증가 횡변위(monotonic pushover)** 로 상부를 밀어 역량곡선 비교.
  주의(PEER §9.2): monotonic 은 cyclic 대비 **저 drift(≤0.75%)에서 강성·강도를 다소 과대평가**
  (반복열화 R 미반영). 1차 비교는 포락선 일치 정도로 판단.

## 8. 검증 비교 대상
- **밑면전단력(횡하중) – 상부 횡변위 곡선** (PEER Fig 7.27: 측정 vs 예측)
- 우리 1차 합격선: monotonic pushover 곡선이 실험 포락선의 초기강성·항복점·최대강도와
  대체로 겹치면 OK(저 drift 과대평가는 monotonic 특성으로 감안).
